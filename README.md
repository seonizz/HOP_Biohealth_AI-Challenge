# 말씨 — 현재 프로젝트 한눈에 보기

어려움을 겪는 사람 곁의 가족·친구가 대화와 행동을 준비하도록 돕는 서비스입니다. **2026-11-17 기준 v3 질문셋에 답변 기반 맞춤 질문을 추가했고, 관리자 페이지에서 12B·31B와 질문 호출·검토 역할을 설정할 수 있습니다.** 구현 통합과 실모델 최종 검증 상태는 [최근 변경 기록](app/docs/RECENT_CHANGES_2026-11-17.md)에서 구분합니다.

질문셋 버전은 **`malssi-intake-3.0.0-rc1`**, 루트·앱 npm 패키지 버전은 **`0.1.0`**입니다. 질문셋 교체를 앱의 정식 3.0 출시나 모델 교체로 해석하지 않습니다. 원본 묶음은 참조 후보(`reference_only`, `production_approved=false`)이며, 앱 연결 범위와 검증 근거는 아래 문서로 관리합니다.

| 지금 볼 항목 | 현재 기준 | 자세히 보기 |
|---|---|---|
| 현재 질문셋 | 기본 9문항 + 조건부 확인 1문항 + 맞춤 추가 최대 2문항. 필수 개수가 아니며 맥락에 따른 생략 유지 | [v3 질문 계약](app/docs/QUESTIONS.md) |
| 모델 실행 설정 | `app/` · `/admin/models` · 기본 단독 범용 모델 질문 1회, 최종 카드 생성·검토 별도 | [모델 실행 설정](app/docs/MODEL_EXECUTION_SETTINGS_2026-11-17.md) |
| 사용 흐름 | 질문 답변 → 원문에 근거한 상태 갱신 → 검토된 가이드 → 기록; 이전 기록·질문 스냅샷 보존 | [v3 적용·호환성](app/docs/QUESTIONS.md#판본db기존-기록) |
| 실행 방법 | 프로젝트 루트의 공통 명령, 앱별 DB·모델 연결 설정 | [실행·검사 안내](docs/current/실행과_검증.md) |
| AI 에이전트용 모델 테스트 | 질문셋 JSON → 앱 AI 호출 → 기대값·응답·토큰·오류 보고서 | [실행 규격과 예시](ai/docs/MODEL_QUESTION_TESTS.md) |
| v3 검증 상태 | 합성 회귀, 저장 답변을 재개한 생성·저장, 새 대화 전체 검증을 구분 | [실행별 결과와 실패 수정](app/docs/QUESTIONNAIRE_V3_VERIFICATION.md) |
| 데이터·모델 연구 | 31B 전환을 위한 학습·평가 자료와 분류 데이터 | [데이터와 연구](docs/current/데이터와_연구.md) |
| 발표 준비 | 근거정합 발표 기준본·실측 기록, 최종 31B 검증 진행 전 | [발표자료](presentation/README.md) |
