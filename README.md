**2026-11-10 로컬 자료 정리:** [최신·아카이브·미완료 자료](로컬자료_안내.md)에서 시작합니다. 아래 소개와 수치는 각 기준일의 기록이며, 현재 작업 문서는 새 색인에서 구분합니다.

**2026-10-27 결선 준비 갱신:** [엄격 평가 보완·재평가](docs/competition/결선_엄격평가_보완과_재평가_2026-10-27.md)와 [발표 v6 검수본](presentation/final/말씨_결선_실전발표_v6_검수본.pptx)을 먼저 확인합니다. 동일 엄격 기준 **50→53/90점**이며 실제 사용자·전문가 승인·기관 도입은 미확인입니다. 아래 모델·구성 설명은 10월 15일 기록이고, 이번 내부 평가에서 모델 자체·처리시간은 채점하지 않습니다.
