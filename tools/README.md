# Git 반입 검사

`audit_git_privacy.py`는 상담 내용을 출력하지 않고 **Git 인덱스에 들어 있는 실제 blob**을 검사한다. 파일 크기 10MiB 이상, 스테이징된 `.gitignore`로 제외된 파일, 원천 상담의 80자 이상 전체 문자열과 일치하는 값을 거절한다. `.gitignore`의 작업 폴더 수정으로 스테이징된 정책을 우회할 수 없도록 인덱스의 규칙을 별도 임시 폴더에서 대조한다.

```sh
npm run audit:git
python3 -B tools/audit_git_privacy.py --scope staged
npm run test:privacy
```

현재 저장소에는 `core.hooksPath=.githooks`를 로컬 설정해 커밋 전에 staged 검사를 실행한다. 다른 체크아웃에서 연결할 때는 `git config --local core.hooksPath .githooks`를 사용한다. 기존 훅 설정이 있다면 덮어쓰지 않고 해당 훅에서 이 검사기를 호출한다. `MALSSI_PYTHON`으로 훅의 Python 경로를 지정할 수 있다. 원천 파일이 없거나 JSON/압축 내용 검사가 불완전하면 실패하며, 단순 파일 경로 검사를 내용 감사 통과로 대신하지 않는다.

기본 원천 경로는 `.gitignore`로 제외된 `data/데이터셋/말씨_원본상담_SFT_v1_20261009`다. 다른 위치는 `--source-dir`로 지정한다. 결과 파일은 `--output runtime/...json`으로 저장하며 원문은 넣지 않는다. 감사 중 파일·인덱스·Git 이력을 수정하지 않는다.

`.json`, `.jsonl`, `.ndjson`은 **UTF-8(선택적 UTF-8 BOM 포함)**만 허용한다. 일반 바이너리 분류보다 먼저 해석하며 UTF-16·UTF-32·CP949 등 다른 인코딩, 잘못된 UTF-8, JSON 문법 오류와 원시 NUL은 오류로 보고해 커밋을 차단한다. UTF-16을 자동 변환하거나 내용 검사를 했다고 표시하지 않는다. `.json.gz` 등 압축 해제 후와 Office 내부의 같은 확장자 첨부에도 이 규칙을 적용한다. 오류에는 경로와 예외 종류만 남기고 원문·파서 오류 메시지를 출력하지 않는다. [v8 G2 수정 기록](../docs/competition/결선_재평가_지적_수정_v8.md)에 실패 재현과 회귀검사 근거가 있다.

**같은 객체의 중복 JSON 키는 값과 관계없이 거절**한다. Unicode escape를 해석한 키를 모든 깊이에서 확인하므로 앞값이나 객체 전체가 덮여 원문이 사라지는 경우도 `DuplicateJSONKeyError`로 차단한다. 서로 다른 객체·JSONL 행에서 같은 키를 사용하는 것은 허용한다. 이 규칙은 gzip·Office 첨부와 대조용 원천 JSONL에도 적용한다. 인덱스 파일의 중복 키는 CLI 종료코드 1, 원천 자료의 중복 키로 감사를 완료할 수 없는 경우는 종료코드 2다. 오류에 키·값을 출력하지 않는다.

일반 ZIP/TAR/7z/RAR 등 불투명 묶음은 로컬에 보관하고 검토 가능한 개별 코드·문서만 추적한다. Office 문서는 필수 패키지 구조 확인 후 XML 텍스트와 내부 첨부 텍스트/Office를 검사하며, 불투명 바이너리 첨부는 거절한다. 단순히 `.zip`을 `.pptx`로 바꾸는 경우도 실패한다.

**한계:** JSON 이외의 해석하지 못한 바이너리는 `binary_not_scanned` 수로 표시하며 내용 검사 완료로 세지 않는다. 짧거나 변형된 발췌, 일반 문서의 부분 문자열, 이미지 OCR·은닉 데이터, 과거 커밋·원격 공개 여부는 이 검사로 배제하지 않는다. 통과는 해당 규칙과 대조 범위의 통과이며 상담 원문이 어디에도 없다는 인증이 아니다. 원문·학습 행·라벨/수치 행렬은 크기와 관계없이 로컬 제외 경로에만 보관한다.

2026-10-16 정리에서는 `ai/outputs/**/private/`의 1,221파일과 불투명 압축 묶음 2개를 로컬 해시 보존 상태로 추적 해제했다. 기존 v7이 확인한 174파일의 원문 완전 일치는 현재 인덱스에서 0개다. 과거 Git 이력 재작성·원격 변경은 실행하지 않았다.
