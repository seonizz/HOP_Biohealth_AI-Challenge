# 검증 문서 안내

새 질문셋 `malssi-intake-3.0.0-rc1`의 코드·DB 회귀와 실제 모델 실행별 결과는 [v3 교체 검증](QUESTIONNAIRE_V3_VERIFICATION.md)에 기록합니다. 새 대화 전체 경로의 성공 여부와 저장된 답변에서 결과만 재생성한 성공을 구분합니다.

통합 프로젝트의 검증 결과와 미확인 범위는 [현황과 할 일](../../docs/current/현황과_할일.md), 재현 명령은 [실행과 검증](../../docs/current/실행과_검증.md)에 모았습니다.

이전 모델·UI·DB 검증과 배포 이력은 [보관 문서 안내](../../docs/archive/README.md)를 참고합니다. 예전 `archive/08_문서통합_원문/app/docs/VALIDATION.md` 원본은 이 체크아웃에 없으며 복구하거나 현재 검증 근거로 사용하지 않았습니다. 과거 통과 결과를 현재 코드의 검증 결과로 합산하지 않습니다.
