# 근거 기반 상세 안내 선별 통합

통합일: 2026-10-16 (Asia/Seoul).

대상은 [codex/grounded-detailed-guides](https://github.com/seonizz/HOP_Biohealth_AI-Challenge/tree/aae493e6add14537469723c245d995ab6d2cca6d)이며, 현재 `main`의 `1bbda56`을 기준으로 핵심 구현을 통합했다. 대상의 루트 앱과 현재 `app/`는 공통 Git 조상이 없어 전체 파일 교체나 무관한 이력 병합 대신 기능별로 이식했다. 원본의 주요 구현 커밋은 `eea9753`, `2c2a30e`, `b64e8cb`이다.

## 반영한 기능

- 원문 관찰·관계 메모리·주장별 근거 검토를 나눈 상태 갱신.
- 이미 답한 질문의 근거 있는 생략, 제한된 선택적 확인 질문, 현재 위험의 별도 검토.
- 전략 검토, 카드별 작성, 첫마디·듣기·제안 분리 작성과 통합, 발화·돌봄·최종 검토.
- 문제 카드만 수정하고 즉시 검증하며 다른 카드는 보존하는 복구.
- 최종 발화와 일치하는 단계별 설명·원문 근거의 저장과 표시.
- 실제 완료 단계 기반 진행 조회, 전체 폭 행동 카드, 다음 단계 카드, 접힌 대화 내역.
- 실행기별 출력 형식 설정. 원문·형식·길이·안전 검증은 모든 전송 방식에서 유지.

현재 프롬프트 버전은 `relationship-v3.9-grounded-details-safety-selection`이다. API와 상세 계약은 [API](API.md), [관계 에이전트](RELATIONSHIP_AGENT.md)에 반영했다.

## 보존한 현재 수정

- 빈 답변·보이지 않는 문자·필수 입력 우회 차단, 정상 Unicode와 원문 보존.
- 안전 문항 ID 선택 후 전체 원문·직접 입력·후속 정정 복원, 출처별 검색 일치 검증.
- 서버가 구성하는 관찰 요약·보고 메모리, 근거 없는 가설의 제한된 재시도.
- 미완료·완료 대화 삭제, 전체 삭제의 `conversation_epoch`, 늦은 생성·응답에 의한 복원 차단.
- 소유자 격리·암호화·CSRF·버전 충돌, 실패 답변 보존과 중복 요청 공유.
- 소스 해시·프롬프트 버전·요청/생성/시도 ID와 재시도 대기 로그.
- 간결한 서비스 안내 원칙, 기존 평가 기록과 학습 데이터 평가 기준, 현재 미완료 과제.

`store.js`, 삭제 마이그레이션, 입력 내용 판정 유틸리티, `model-schema.js`, 원문 구성요소·검색 모듈은 기존 구현을 유지했다. 학습 데이터·모델·실제 평가 출력·다른 장비 실행 스크립트·과거 평가 수치는 가져오지 않았다.

통합 검토 중 조기 종료가 짧은 기본 답변의 미완료 후속 질문을 지우면서 원문도 잃는 결함을 발견했다. 후속 답변을 꾸미지 않고 이미 받은 기본 답변을 먼저 확정하도록 수정하고 회귀검사를 추가했다.

## 검증 범위

일회용 PostgreSQL 16과 합성 모델 응답으로 앱 전체 **371개 통과, 실패 0, 제외 0**을 확인했다. 평가 근거 도구 **24개 통과**, `npm run check`의 JavaScript·JSON 검사와 `git diff --check`도 통과했다. 진행 조회의 소유자 격리·중복 요청·실패·삭제, 기존 긴 안전 원문·후속 정정·입력 우회·삭제 경합을 함께 검증했다. 결과 카드의 이전 기록 호환 배치는 로컬 브라우저에서도 확인했다.

실제 모델 생성 품질·체크포인트 교체·외부 배포는 이번 통합 검증 범위에 포함하지 않는다. 브라우저 확인은 기존 합성 결과의 배치 확인이며 전체 브라우저 E2E 검증은 아니다.

## 남겨 둔 개선 과제

대상 브랜치의 작업 정리에 있던 다음 의미 품질 과제는 해결 완료로 바꾸지 않는다.

- 전체 발화 통합 뒤 열린 질문·사용자 목적·거절 선택권·경계가 충분히 보존되는지 확인.
- 사용자가 보고하지 않은 심리 상태·원인·무제한 도움 약속을 의미 단위로 검토.
- 설명의 각 주장을 인용이 실제로 지지하는지 확인.
- 사용자 돌봄이 상대를 돕는 의무에 치우치지 않도록 평가.

기존 [현황과 할 일](../../docs/current/현황과_할일.md)의 독립 평가 자료, 데이터 의미 검토, 실제 참여자 관찰, 운영 보유·삭제 정책, 결선 증거 과제도 그대로 유지한다. 이번 통합이나 자동 검사 통과를 평가 점수 상향·실제 답안 품질 인증으로 사용하지 않는다.
