# 최근 앱·모델 실행 변경 — 2026-11-17

이 기록은 v3 질문셋 교체 이후의 로컬 변경을 main에 통합하기 위한 설명이다. 모델 학습 데이터·가중치·비밀키·원문 요청/응답·실행 캐시는 포함하지 않는다. 코드 업로드와 실행 중인 서비스 재시작, 실모델 최종 검증 성공은 별개다.

## 현재 기능

- `/admin/models`에서 12B·31B 기본 모델, 기존 OpenAI 호환 연결, 질문 1회·최대 2회·단계별 처리와 개별·병렬 실행, 질문용·검토용 역할을 설정한다. 같은 범용 모델을 두 역할에 사용할 수 있다. 기본은 단독 범용 모델의 질문 1회이며 최종 카드는 기존 범용 모델 생성·검토 흐름을 유지한다. 진행 중인 대화는 저장된 설정을 유지한다.
- 기본 질문 문구·보기·도움말은 2026-11-13 첨부 v3 원본과 일치한다. 기본 9개는 필수 체크리스트가 아니다. 이후 사용자 요청에 따라 답변 기반 순서 선택과 맞춤 추가 질문 최대 2개를 구현했다. 새 대화의 최대 12개는 기본 9개·Q10 한 번·추가 질문 2개의 합계이며 목표 질문 수가 아니다.
- 개인화는 실제 답변의 원문·수정번호·구간에 연결한다. 수정된 원문에서 파생된 질문/답변은 연쇄 무효화하며, 질문 문장 자체를 사용자가 말한 사실로 저장하지 않는다. 전송용 출처 ID는 서버에서 정확한 원문 구간으로 복원하고 기존 검증을 적용한다.
- 사용자 답변을 즉시 표시하고, 검증된 카드부터 표시하며, 최종 DB 저장이 완료된 뒤 완료 응답을 보낸다. 연결 종료·재시도·취소와 오래된 결과의 저장 차단을 보강했다. 카드 배치·색상·표시 범위는 기존 기준을 유지한다.
- 최종 카드 생성 시 상황·행동·감정·관계·변화·근거를 내부적으로 상세화하는 선택 기능을 추가했다. 반복 문장이 과도한 카드는 검토 전에 해당 카드만 제한적으로 재생성한다. 반복 내용을 잘라 정상 결과로 승인하지 않는다.
- GPU 실험 실행·역할 비교·출력 검토·시간 계측 코드를 보존한다. 입력 토큰·출력 토큰·대기·추론·첫 토큰·요청별 호출 수·최종 저장을 구분한다. 모델 첫 토큰 시간은 화면에 문장이 보이는 시간과 다르다.

## 질문 부담에 대한 판단

초기 통합 `668bc07`은 질문 상한이나 순차 진행을 줄이지 않았다. 이후 사용자의 “목적과 상황부터, 보통 2~4개” 요청으로 새 대화의 자동 순차 진행을 제거했다. 현재는 목적 → 상황 다음에 꼭 필요한 질문을 명시적으로 선택해야 계속하며, 이미 답한 내용은 다시 묻지 않는다. 4개를 채우지 않고 필요 정보가 충분하면 종료한다. 질문은행·예외 상한·기존 저장 대화는 보존하며, 상세 구현과 검증은 [짧은 질문 흐름](COMPACT_QUESTIONS_2026-11-17.md)을 따른다.

## 실모델 증거와 미완료 사항

12B 실모델의 이전 비교에서 두 설정 모두 기본 9문항을 처리했다. 기본 1회는 질문당 정확히 1회, 평균 105.236초였다. 단계별 병렬 설정은 평균 6.111회·506.238초였다. 평균 기준 시간은 약 79.2%, 호출 수는 약 83.6% 적지만 질문 순서와 내부 처리가 달라 통제 반복실험은 아니다. 단일 GPU 워커는 실제 추론을 직렬로 처리했다.

1회 설정의 Q7 125.078초·Q8 123.212초는 120초 목표를 초과했다. 모든 질문이 2분 안에 끝난다고 주장하지 않는다. 이후 카드 반복 복구는 양쪽에서 성공했지만, 최종 검토 묶음이 입력/출력 문맥 용량을 초과해 두 설정의 최종 DB 저장은 완료되지 않았다.

최근 격리 12B worker는 기본 출력 8,192토큰을 전부 예약하고, 입력과 합계가 32,768토큰을 초과하면 `context_length_exceeded`를 반환하도록 수정했다. 기존 앱은 이 명시적 오류를 받아 검토 태스크를 원문 삭제 없이 분할한다. 이 worker는 전용 환경용 실험 코드이며 운영 앱 기본 연결에 자동 적용하지 않는다. 새 GPU 검증은 별도 백그라운드 실행이며 결과 확인 전까지 실모델 최종 저장 성공으로 표시하지 않는다.

해당 재검증은 이전 질문의 실모델 요청/응답을 정확히 대조해 상태를 재현하고 최종 생성·검토·저장만 새로 호출한다. 질문 재현 시간을 새로운 실모델 속도로 집계하지 않는다. 기존 실패 증거는 보존한다.

## 문서 우선순위와 검증

현재 질문 규칙은 [질문 계약](QUESTIONS.md), 맞춤 질문은 [개인화 계약](PERSONALIZED_QUESTIONS_2026-11-17.md), 모델 호출/역할 설정은 [실행 설정](MODEL_EXECUTION_SETTINGS_2026-11-17.md)을 따른다. 11월 16일의 서비스 접속·병렬 인계 문서와 개별 실험 보고서는 해당 시점의 기록이며 이후 설정을 덮어쓰지 않는다.

업로드 전 앱 전체 회귀는 별도 로컬 PostgreSQL DB에서 실행하며, AI 실행기 회귀와 인덱스의 파일 크기·학습 원문·비밀정보 포함 여부를 별도로 검사한다. 모델 응답을 대역으로 사용한 DB 검사가 실모델 생성 품질을 입증하지는 않는다.
