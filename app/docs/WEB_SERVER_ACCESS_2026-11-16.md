## 관리자 페이지에 있는 기능

1. **새 대화에 사용할 모델:** 12B 또는 31B를 선택하고 “설정 저장”을 누른다. 현재 선택은 31B다. 진행 중인 대화와 기존 기록에는 적용되지 않는다.
2. **모델 연결 설정:** 기존 12B·31B의 API 기본 URL, 모델 이름, API 키를 수정한다. 제3 모델을 추가하는 화면은 아니다.
3. **연결 상태:** API 키의 설정 여부와 질문당 1회 호출 고정 여부를 보여 준다. 키 값은 조회하지 않으며 키 입력을 비우면 기존 키를 유지한다.
4. **연결 저장과 기본 모델 저장은 별개:** API 연결을 바꿨다고 기본 선택까지 바뀌지 않는다. 연결 변경은 새 불변 버전으로 저장해 기존 대화의 연결을 보존한다.

현재 31B는 `malssi-gemma4-31b-step5128`, Mac 내부 모델 API는 `http://127.0.0.1:18731/v1`이다. 해당 API는 전용 키가 필요하며 일반 웹 접속 주소로 사용하지 않는다. 질문당 1회 호출 고정은 **꺼짐**이다. 앞선 실제 검증의 생략 검토 불일치와 최종 상세 검토 실패를 이유로 승인하지 않았으며, 이를 우회하지 않고 독립 검토를 유지한 상태로 사용한다. 검토 실패 시 결과가 저장되지 않고 오류가 표시될 수 있다.
