## 적용 범위

격리 프로필 `app/config/gpu31b-single-call.env`에서만 `MODEL_SINGLE_CALL_TURNS=true`를 설정한다. 기본 서비스 설정과 기존 2회 호출 프로필은 유지한다. `relationship_agent` + `combined` 모드에서 사용하고, `MODEL_BUNDLE_COMBINED_TURN_REVIEWS=false`가 필요하다.

답변 1건당 상태 갱신·다음 질문 판단을 하나의 `turn_draft` 생성 요청으로 처리한다. 형식·원문 근거·질문 계획 검증은 서버에서 수행한다. 내부 형식 재시도, 바깥 작업 재시도, 블록 분할 복구를 비활성화하여 실패한 답변 요청도 모델 생성 POST가 1회를 넘지 않게 한다. 연결 준비나 토큰 용량 조회는 생성 호출 수와 별도로 구분한다.

독립적인 상태·질문·안전 모델 검토는 해당 턴에서 생략한다. 이 결과는 `state_agent.reviewed=false`, `mode=single_call`로 기록하며 검토 완료 판정의 재사용 대상으로 삼지 않는다. 구조·원문 검증만으로 의미 정확성을 보장하지는 않는다. 근거 없는 생략을 허용하거나 생략한 문항의 답변을 생성하는 규칙은 추가하지 않는다.

긴급 판단 초안은 독립 검토 없이 승인하지 않는다. `single_call_safety_review_required`로 중단하여 저장·다음 질문 진행을 막는다. 일반 대화의 최종 결과 생성 시에는 기존 `safety_review_final` 및 최종 결과 검토·수정 경로를 유지한다. 따라서 **최종 결과 생성까지 모델을 단 한 번 호출한다는 의미는 아니다.**
