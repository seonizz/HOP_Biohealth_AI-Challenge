외부 주소로 접속할 때는 관리자 로그인이 필요합니다.

현재 설정을 확인하고 있어요.

별도 모델을 지정하면 답변마다 다음 질문 판단에 최대 한 번 호출합니다. 분석과 카드 생성·검토는 대화를 마친 뒤 진행합니다.

범용 모델 연결 · 카드 생성

OpenAI 호환 채팅 API와 구조화된 JSON 출력을 지원하는 연결을 입력해 주세요. 변경한 모델로 새 대화를 시작하면 입력한 주소로 대화 내용이 전송됩니다. 연결 변경은 새 대화부터 적용되며 기본 모델 선택은 바뀌지 않습니다.

최종 카드 생성·검토에는 위에서 분석·카드 역할로 선택한 모델의 연결을 사용합니다.

질문 실행 설정

분석·카드 모델을 ‘대화 모델 사용’으로 선택한 새 대화에 적용됩니다. 기본은 범용 모델로 질문마다 1회 호출입니다.

1회는 별도 검토·추가 재시도를 하지 않습니다. 2회는 실패해도 호출 한도를 넘지 않습니다. 단계별은 제한된 자동 복구를 사용합니다. 병렬은 독립 작업에만 적용하며, 생성 결과의 검토는 결과가 나온 뒤 실행합니다. 1회·2회 설정을 병렬로 바꿔도 같은 요청을 복제하지 않습니다.

질문용 연결

1회 호출에서는 검토용 모델을 호출하지 않습니다. 연결을 미리 저장해 두고 검토 모드에서 사용할 수 있습니다.
