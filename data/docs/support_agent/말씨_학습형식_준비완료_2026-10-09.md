## 원본과 변환 코드의 대조

원본 1,107개 상담·303,522개 발화를 SQLite 및 기존 고정 릴리스와 대조했다. 원본 DB 해시는 `da1511a77e13e51769be7bba2169c2e838b290693a384e67b5c568bb314bd10e`다. 원본·기존 분류 릴리스는 수정하지 않았다.

발화 역할의 `상담사`와 `상담자`를 상담사로 명시 매핑했다. 기존 제외 목록 216개에는 추가 검토 8개가 이미 포함돼 있어 이중 적용하지 않았다. 줄바꿈 때문에 문서 줄 번호와 DB 발화 순번이 다른 실제 사례를 확인해 누적 원문 줄 기준으로 연결했다. 단어 위치 역시 원문 발화 기준임을 확인해 문장 내부 위치와 별도로 저장하고 둘 다 검사한다.

각 예시는 첫 원본 발화부터 현재 목표까지의 접두 구간이다. 중간 발화를 지우거나 미래 발화를 가져오지 않는다. 기존 자료 수집·분류 배정 노출이 나타난 뒤의 후보는 보류하고, 이전의 온전한 접두 구간만 사용했다. 과거 상담사 응답은 입력으로만 두고 마지막 목표 응답만 메시지 손실 마스크 `1`로 표시했다.

## 추가 감독 정보

24개 상담에서 감정 설명과 HOP 적용 여부를 검토한 **AI 주석 24개**를 별도 파일로 만들었다. 기존 split은 train 21개·validation 3개, 원천 그룹은 23개다. 감정 근거는 명시 22개·잠정 1개·근거 부족 1개이며 인용 구간은 49개다.

이 중 10개는 주변인 지원 요청자의 역할 확인이 필요하고 14개는 직접적인 보호자 지원 요청이 없다. 원래 내담자를 보호자로 바꿔 학습 정답을 만들지 않았다. 24개 모두 `training_allowed:false`, `human_verified:false`인 초안으로 기본 SFT에서 분리했다. 독립 검토에서 관계 주체를 잘못 표현한 주석 1개를 원문에 맞게 수정했다. 6개 주석은 본 SFT의 보존 구간 이후이고 3개는 첫 검토된 범주 노출 이후이므로, 원천 상담과 split이 같다는 이유로 본학습에 자동 결합하면 안 된다. 추가로 탐색한 3개 보호자 후보는 앞선 자살 사별·학대 호소·자녀의 귀가 공포 맥락이 있어 일반 HOP 행동 정답으로 채택하지 않았다.

별도로 작성했던 합성 32시나리오·64응답은 작업 폴더의 보조 초안으로 보존하며 이번 원본 SFT 패키지에는 혼합하지 않는다. 기존 사람·전문가 승인 생성 학습 게이트를 우회해 승인 기록을 만들지 않았다. 새 `source_sft.py`는 원본 응답 재현을 위한 명시적인 연구 준비 프로필이다.

## 검증 증거

- 데이터 파일 9개와 선언 해시·건수 일치.
- 45,974개 SFT 행의 원본 접두 구간·목표 응답·마지막 응답 마스크 재구성 검사 통과.
- 문장 513,170개, 단어 등장 4,496,325개의 원문 구간 및 출처 대조 통과.
- 검사 범위에서 원천 그룹의 학습·검증 교차 0, 중복 마지막 문답 쌍 0, 미래 발화 유입 0, 잘못된 메시지 손실 마스크 0.
- 전체 회귀 테스트 **174개 통과**. 새 원본 SFT 테스트 **24개**는 일반 실행과 `python -O` 모두 통과.
- 독립 코드 검토에서 찾은 필수 파일 목록 누락, 음수 위치, 목표 순번 변조, 병합된 빈 발화, 피상담자 분할 교차, 불리언 마스크·순번, 응답 중간 절단, 위치 기준 위조를 보완하고 회귀 검사를 추가.

근거 파일은 패키지의 `audit.json`, `source_statistics.json`, `verification/`, `supplementary/`와 [데이터 계약](말씨_원본상담_SFT_데이터계약_2026-10-09.md)에 있다. 전수 검사는 구조·원문·분할의 정합성 검사다. 45,974개 응답의 의미·임상 품질을 사람이 전수 승인했다는 주장은 아니다.

## 남은 범위

실제 모델 템플릿·토크나이저로 마지막 응답의 토큰 경계를 확인하고 길이 초과를 처리하는 작업은 GPU 서버의 학습 준비 단계에 남아 있다. 문자 길이 최댓값은 train 45,550자·validation 25,105자이며 토큰 길이가 아니다. 임의 절단으로 문맥을 잃지 않도록 계약에 보류·집계를 명시했다.

말씨의 최종 목적을 위해서는 실제 주변인 요청과 지원 행동의 정답을 더 확보하고, 전문가의 의미·안전 검토, 원천 이용 조건 확인, 별도 테스트 세트 및 실제 모델 응답 평가를 완료해야 한다. 이번 결과는 그 단계를 마쳤다는 선언이 아니라, 원본 상담사 응답 학습을 시작할 수 있게 데이터를 재구성하고 검증한 산출물이다.
