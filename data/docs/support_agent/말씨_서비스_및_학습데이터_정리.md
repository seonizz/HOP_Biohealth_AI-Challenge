# 말씨 서비스 및 학습 데이터 정리

최신 검증: [2차 검증 수정 결과](말씨_2차_검증_수정_결과.md).

작성일: 2026-10-09 · 기준: 사용자 확정 서비스 정의와 현재 로컬 데이터셋

후속 검증: [실데이터·코드 검증 및 수정 결과](말씨_실데이터_코드_검증_및_수정_결과.md). 생성 학습의 승인·분할·입력 검사와 회귀 평가 도구를 추가했으며, 실제 모델 학습·응답 평가는 여전히 미진행이다.

> 목표는 가족·주변인의 상황을 듣고, 실제로 건넬 말과 실행 가능한 행동을 안내하는 한국어 상담 에이전트 모델을 개발하는 것이다. 현재 확보한 3종 데이터는 보조 분류 학습용이며, 말씨의 응답 생성 학습 데이터와 LLM 학습은 아직 완성되지 않았다.

## 1. 서비스 정의와 대상

**서비스명: 말씨**

불안·우울·중독 등을 겪는 당사자 곁의 가족·주변인을 위한 대화법 및 행동 가이드 AI 상담 에이전트다.

- **주요 사용자:** 우울증, 불안장애, 각종 중독을 겪는 가족을 둔 부모, 배우자, 자녀, 형제·자매 등 보호자.
- **추가 사용자:** 힘든 사람이 주변에 있어 돕고 싶지만 어떻게 말해야 할지 모르는 친구, 연인 등 가까운 주변인.
- **다루는 어려움:** 우울, 불안, 알코올·도박·디지털 등 중독 관련 어려움. 진단이나 어려움의 종류가 확인되지 않은 상황도 구분해 다룬다.

데이터에서는 **도움을 요청하는 사용자**와 **사용자가 돕고 싶은 당사자**를 구분한다. 사용자의 관찰·해석·전언을 당사자에게 직접 확인한 사실로 취급하지 않는다.

## 2. 모델이 학습해야 할 내용

모델의 핵심 학습 단위는 다음과 같다.

**현재까지의 주변인 대화와 확인된 정보 → 다음 행동 선택 → 필요한 질문 또는 구체적인 대화·행동 안내**

| 학습할 능력 | 기대하는 동작 |
| --- | --- |
| 상황과 요청 이해 | 사용자와 당사자의 관계, 현재 알려진 사실, 사용자가 원하는 도움을 파악한다. |
| 필요한 질문 선택 | 답변에 꼭 필요한 정보가 부족할 때만 질문한다. |
| 질문에서 지원으로 전환 | 현재 요청에 답할 정보가 충분하면 질문을 멈추고 안내한다. |
| 실제 대화 예시 생성 | 사용자가 당사자에게 건넬 수 있는 구체적인 말을 제시한다. |
| 실행 가능한 행동 안내 | 관계, 의향, 사용자의 부담과 한계를 고려한 행동을 제안한다. |
| 문맥 유지 | 이미 말한 내용, 모름, 거절을 반영하고 같은 질문을 반복하지 않는다. |

기존 **17문항 질문은행**은 필요한 질문을 고르는 자료로 재사용한다. 모든 사용자에게 17문항을 전부 묻거나, 매 응답에 긴 고정 양식을 강제하지 않는다.

설계상의 다음 행동은 `ASK_CFI`(질문은행 질문), `CLARIFY`(명료화), `SUPPORT`(지원), `SUPPORT_LIMITED`(확인된 범위의 지원), `SAFETY_SUPPORT`(안전 우선 지원), `END`(종료)로 구분한다.

## 3. 학습 데이터셋 3종의 역할

사용자가 확정한 데이터 단위는 **상담 전체·문장별·단어별**이다. 아래 항목은 말씨 목적에 맞춰 추가할 주석 설계이며, 해당 라벨링이 모두 완료되었다는 의미는 아니다.

| 데이터셋 | 말씨에서 학습할 내용 | 추가할 주요 주석 |
| --- | --- | --- |
| 상담 전체 | 상황과 목적 이해, 질문 선택, 지원으로 전환하는 시점, 대화 흐름 유지 | 사용자 역할, 당사자와의 관계, 현재 목적, 정보 출처, 다음 행동, 지원 전략, 목표 응답 |
| 문장별 | 관찰과 해석 구분, 공감, 확인 질문, 대화 예시, 거절 대응, 관계 회복, 경계 설정 | 화자, 지칭 대상, 시점, 진술 상태, 의사소통 기능, 지원 의도, 근거 구간, 문맥상 응답 적절성 |
| 단어별 | 핵심 표현과 근거 위치 연결, 부정·인용 구분, 표현의 문맥상 역할 이해 | 원문 문장 ID, 표현 위치, 지칭 대상, 부정 여부, 인용 여부, 문맥상 역할 |

상담 전체는 원천 보관 단위다. **다음 응답을 학습할 때는 현재 턴까지의 대화만 입력으로 사용**하고, 미래 발화·후속 반응·정답 요약이 입력에 섞이지 않도록 한다.

문장과 단어는 원문 상담 및 주변 문맥과 연결한다. 단독 단어의 라벨만으로 진단, 위험도 또는 적절한 응답을 결정하지 않는다. 단어 데이터의 어휘 묶음은 LLM의 토크나이저 토큰과도 구분한다.

## 4. 라벨링과 ‘기타’ 처리 기준

기존 `우울·중독·불안·기타` 라벨은 내용의 주제와 의미를 이해하는 **보조 정보**로 사용한다. 좋은 상담 응답인지, 어떤 말이 도움이 되는지에 대한 정답을 대신하지는 않는다.

- 판단 가능한 항목은 근거를 남겨 최대한 라벨링한다.
- 판단 불가나 정보 미확인은 별도 보류 상태로 두고, 기타로 강제 배정하지 않는다.
- AI 의미 라벨과 기존 통계 기반 라벨을 구분한다. AI 의미 판단만으로 통계 조건을 통과했다고 처리하지 않는다.
- 기존 분류 실험에서는 기타 비중을 낮추는 샘플링을 유지할 수 있다.
- 에이전트 학습에서는 공감, 확인 질문, 자율성 존중, 관계 조율, 경계 설정, 보호자 자기돌봄에 필요한 문장을 기타라는 이유로 제거하지 않는다.

문장 기능 라벨의 설계 예시는 관찰 보고, 당사자 발화 전달, 사용자 해석, 사용자 감정·부담, 공감·반영, 열린 질문, 명료화, 자율성 존중 제안, 사과·관계 회복, 경계 설정, 도움 연결, 안전 확인, 일반 맥락, 판단 보류다.

데이터 균형은 질환 주제 외에도 관계, 사용자 목적, 다음 행동, 정보 부족·모름·거절, 대화 단계 등을 함께 고려한다.

## 5. 응답 생성 학습 데이터 구성 원칙

한 학습 사례에는 현재까지의 대화, 그때까지 확보한 출처 있는 정보, 다음 행동, 목표 응답을 연결한다. 목표 응답에는 상황에 따라 필요한 질문, 실제로 건넬 말, 가능한 행동, 반응에 따른 조건부 다음 말을 포함한다.

| 구분 | 기록 원칙 |
| --- | --- |
| 원본 상담 | 실제 화자와 내용을 보존하고 원천 위치를 연결한다. |
| 원본을 각색한 사례 | 각색 사실과 원천 상담을 표시한다. 관계나 관찰 내용을 추가했다면 실제 관측 사실과 구분한다. |
| 합성 사례 | 합성임을 표시하고 실제 상담 기록처럼 취급하지 않는다. |
| 검토 상태 | AI 초안, 검토된 응답, 평가용 정답을 구분한다. 실제 검토 없이 승인 상태를 부여하지 않는다. |

원본 내담자 발화를 보호자 발화로 임의 변경하지 않는다. 원본 상담사 응답도 말씨에 적합한 정답으로 자동 승인하지 않는다.

응답 생성 학습에서는 목표 assistant 출력에 손실을 적용한다. 원본 상담과 그 파생·각색 사례는 동일한 학습/검증 구분에 배정해 데이터 누출을 막는다. 동일 인물 정보는 확인 가능한 범위에서 함께 묶고, 확인되지 않은 동일성을 추정으로 확정하지 않는다.

현재 보조 분류 패키지: `학습용_3종_v1_20261009`

| 데이터셋 | 학습 | 검증 | 합계 |
| --- | ---: | ---: | ---: |
| 상담 전체 | 990 | 117 | 1,107 |
| 문장별 | 1,440 | 206 | 1,646 |
| 단어별 | 302 | 76 | 378 |

문장 기타는 185건으로 전체 문장 데이터의 약 11.2%이며, 단어 기타는 123개다. 학습 패키지에 채택한 건수는 전체 검토·라벨링 건수와 다르다.

기존 분류 패키지는 수치 입력과 타깃, 학습/검증 분할, 로더 및 실행 코드를 갖추고 분류 기준 모델의 학습·예측과 파일 검증을 완료했다. 이 실행은 TF-IDF와 Naive Bayes를 사용한 분류 검증이다.

분류 성능만으로 상담 에이전트의 응답 품질을 평가할 수는 없다. 현재 상태는 이번 작업에서 확인한 로컬 자료를 기준으로 한다.

## 7. 다음 구축 단계와 평가 기준

1. 보호자·주변인 시점이 확인되는 사례를 선별하고, 당사자 본인 상담과 구분한다.
2. 사례마다 문맥, 사용자 목적, 정보 출처, 다음 행동, 지원 전략을 주석으로 연결한다.
3. 필요한 질문이나 구체적인 대화·행동 안내를 목표 응답으로 작성하고 검토 상태를 남긴다.
4. 원천과 파생 사례가 학습·검증 양쪽에 걸치지 않도록 분할한다.
5. 기반 모델을 선정한 뒤 응답 생성 학습과 별도의 서비스 평가를 진행한다.

평가에서는 요청에 직접 답하는지, 사용자와 당사자를 구분하는지, 없는 사실을 만들지 않는지, 불필요한 질문을 반복하지 않는지, 실제 사용할 수 있는 말과 행동을 안내하는지 확인한다. 모름·거절, 관계와 한계, 급박한 안전 우려에 맞는 대응도 평가한다.

진단이나 약물 처방·변경은 학습 목표로 두지 않는다. 당사자의 속마음이나 앞으로의 반응을 관측 사실처럼 생성하지 않는다. 급박한 안전 우려에 대한 구체적 안내는 검토된 정책과 지역 자료를 바탕으로 별도 설계한다. 정의가 확인되지 않은 원본 수치 점수를 임상 위험 점수로 사용하지 않는다.
