# 말씨 실데이터·코드 검증 및 수정 결과

이 문서는 1차 수정 당시의 기록이다. 후속 결과는 [2차 검증 수정 결과](말씨_2차_검증_수정_결과.md)를 확인한다.

검증일: 2026-10-09

**첨부 보고서의 지적을 실제 데이터·코드에 대조하고, 학습 자료의 승인·분할·입력·무결성 검사와 회귀 평가 경로를 구현했다. 기존 분류 데이터의 무결성은 확인했으며, 생성 응답 데이터와 실제 모델 평가는 아직 완료되지 않았다.**

검토 원본은 [적대적 검증 보고서](말씨_적대적_검증_원본_2026-10-09.md)다. 문서의 제안을 곧바로 확인된 결함이나 임상 승인으로 취급하지 않고 실제 확인 결과를 아래에 구분했다.

## 2. 실제로 수정한 내용

### 분류 자료 로더의 검사 보강

동결 패키지의 기존 로더는 행 정렬과 타깃을 일부 확인하지만, 파일 해시·CSR 형태·가중치를 충분히 검사하지 않았다. 새 `load_checked_unit` 경로에서 필수 파일의 해시 포함 여부, 행 ID와 순서, 행렬 크기·인덱스·유한값·정규화, 타깃, 학습 가중치를 검사한다. 기존 패키지는 보존하고 현재 데이터 안내를 새 로더로 연결했다.

### 승인된 생성 학습 자료만 내보내는 경로

`agent_training`에 사례 구조, 독립 검토, 원천 사용 근거, split과 시점 검사를 추가했다. `training_allowed=true` 하나만으로 승인되지 않는다. 검토가 정확한 사례 해시에 연결돼야 하며 응답·입력·split이 바뀌면 다시 검토해야 한다. 승인·거절이 충돌하면 자동 승인하지 않는다.

내보낸 학습 파일과 직렬화된 행의 해시도 기록한다. 로더와 배치 생성기가 이를 다시 확인하므로 **승인 후 목표 응답을 바꾸는 경우**를 차단한다. 현재 9개 설계 예시로 실제 내보내기를 시도했을 때 종료 코드 1로 거절했고, 학습 결과 파일을 만들지 않는 것을 확인했다.

### 현재 턴까지의 입력과 주석자 열람 범위 분리

입력과 주석 화면에는 지정한 사용자 턴까지의 메시지만 남긴다. 미래 발화, 기존 정답, 정답 행동, 평가 메타데이터를 제외한다. 같은 앞부분에 서로 다른 미래를 붙여도 입력이 같다는 회귀 검사를 추가했다.

기존 9개 예시는 당시 주석자의 열람 범위 증거가 없어 `legacy_unverified`로 남겼다. 이번 변환만으로 과거 주석의 전향성이나 의미 타당성을 새로 승인하지 않았다.

### 행동 코드와 질문 ID 구분

주된 행동인 `primary_action`과 응답 구성 요소인 `response_components`를 분리했다. 지원과 필요한 확인 질문을 함께 표현할 수 있으며, 질문에는 필요 이유, 제한된 지원에는 정보의 한계, 안전 지원에는 대상이 필요하다.

기존 `demo_04_previous_words_unclear`의 명료화 응답에 붙은 Q16을 새 자료에서 제거했다. Q16은 주변 사람이 권한 방법에 관한 질문이다. 변경 전 값과 근거는 변환 이력에 남겼으며 원본 질문은행과 원본 설계 예시는 보존했다.

### 원천 분할 검사와 평가 기록 결합

원천을 여러 개 사용한 사례는 모든 원천을 연결하고 다른 학습·평가 경로와 함께 검사한다. 독립 코드 검토에서 발견한 `source_root_ids` 문자열을 문자별 원천으로 처리하는 오류도 수정했다. 이제 중복 없는 비어 있지 않은 문자열 목록만 허용한다.

평가 검토 기록은 **사례·입력·평가 기준·출력** 해시에 묶는다. 같은 출력이라는 이유로 다른 사례나 표현 변형의 검토를 재사용할 수 없다. 누락·중복·잘못된 ID와 해시는 오류로 처리한다. 모델 출력만 있으면 검토 대기, 실행·검토가 없으면 미실행이다.

## 3. 지적 사항별 처리 상태

| 지적 | 실제 대조 및 수정 | 남은 범위 |
| --- | --- | --- |
| R1 생성 정답 데이터 부족 | 기존 자료가 보조 분류용임을 확인. 생성 사례·승인·내보내기 수를 분리하고 로더에 승인 검사를 구현 | 실제 보호자 사례와 검토된 목표 응답 확보 |
| R2 강압·감시 요청 | 요청의 목적·수단과 허용 대안에 대한 검토 규칙, 관련 회귀 입력 추가 | 모델이 실제로 준수하는지 평가 |
| R3 안전 주체·폭력·미성년자·한계 | 주체·시점·출처를 유지하는 주석 규칙과 충돌 사례 평가 기준 추가 | 실제 상태 갱신기, 전문 검토 및 지역 안전 정책 |
| R4 자료 이용·제3자 정보 | 원천별 사용 근거와 증거 해시 확인 없이 생성 학습에 진입하지 못하도록 구현 | 권리·허용 범위의 실제 검토, 운영 저장·접근·삭제 체계 |
| R5 행동 경계·질문 중단 | 행동/구성 요소 분리, 질문 필요 이유와 종료 제약, Q16 참조 정리 | 실제 응답에서 불필요한 질문 빈도 평가 |
| R6 미래 누출·사후 편향 | prefix 전용 입력·주석 화면, 근거 span과 해시 검사, 미래 불변성 테스트 | 주석자의 실제 열람 절차 검증, 기반 모델별 배치 확인 |
| R7 모든 학습 경로의 분할 | 분류 자료 전수 검증, 상담·문장 노출 명세 확보, 통합 경로 검사 추가 | 단어 원천 연결 및 전체 파생 경로·근접 중복 검토 |
| R8 검토와 승인 연결 | 사례 해시·검토 항목·검토자·시각·버전·변경된 학습행 검사 | 실제 독립 검토, 검토자 자격·신원 확인 절차 |
| R9 독립 비교 평가 | 30개 공개 회귀 집단과 미실행/검토대기/평가 집계 도구 구현 | 동일 조건 기준 모델 비교와 비공개 보류 평가 |
| R10 보조학습 추가 효용 | 생성 학습만 사용한 후보와 보조학습 후보를 분리하는 평가 계획 유지 | 실제 비교 결과; 3종 모두의 추가 학습을 강제하지 않음 |

R2·R3의 규칙은 주석과 평가를 위한 공학적 기준이며 임상적으로 승인된 위기 절차가 아니다. R4는 위반이 발견됐다는 뜻이 아니라 해당 목적의 사용 근거가 아직 확인되지 않았다는 뜻이다.
