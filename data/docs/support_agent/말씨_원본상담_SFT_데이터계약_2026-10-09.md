# 말씨 원본 상담 SFT 데이터 계약

작성일: 2026-10-09. 사용자 지정: Gemma 4 31B IT, Unsloth 4비트 QLoRA, 자원 부족 시 Gemma 4 12B IT. **학습 실행과 GPU 서버 환경 설정은 이번 작업에서 제외한다.**

## 목적과 세 자료의 역할

말씨는 불안·우울·중독 등을 겪는 사람 곁의 가족·주변인을 위한 대화법 및 행동 가이드 에이전트다. 이번 자료는 그 개발에 사용할 **원본 상담사 응답 재현의 기초 단계**다. 원본 내담자를 보호자로 바꾸거나, 모든 상담을 주변인 지원 사례로 간주하지 않는다.

| 종류 | 내용 | 사용 목적 |
|---|---|---|
| 상담 | 원본 상담사 응답과 그 직전까지의 전체 상담 맥락 | 원본 응답 SFT |
| 문장 | 채택된 대화 접두 구간의 원문 문장, 발화·상담 ID, 위치 | 문맥 복원, 사례 추출, 품질·중복 검사 |
| 단어 | 같은 구간의 원문 단어 등장 건, 문장·발화·상담 ID, 위치 | 연관 표현 탐색과 보조 분석 |

문장·단어 파일을 독립적인 상담 정답으로 학습시키지 않는다. 이전 4분류 패키지의 ‘기타’ 라벨을 임의로 우울·불안·중독으로 바꾸지 않는다. 이번 생성 학습의 정답은 분류명이 아니라 원본 상담사 응답이다. 원래 NORMAL 코호트의 상담에도 활용 가능한 대화가 있으므로 코호트명만으로 일괄 제외하지 않는다. 코호트는 모델 입력에서 제외하고 감사 집계에만 사용한다.

## 상담 JSONL 계약

`conversation/train.jsonl.gz`, `conversation/validation.jsonl.gz`는 UTF-8 JSONL을 gzip 압축한 파일이다. 압축은 저장 형식이며 내용 요약이나 발화 생략이 아니다. `messages`와 `loss_message_mask`가 학습 입력·목표의 계약이다.

- `messages`: 고정 system 안내 뒤 원본 발화의 역할과 텍스트. 마지막 항목은 관측된 상담사 응답이다.
- `loss_message_mask`: 마지막 assistant 항목만 정수 `1`, 나머지는 정수 `0`이다. 원본의 이전 상담사 응답도 입력으로만 사용한다.
- `target_utterance_ids`, `target_start_ordinal`, `target_end_ordinal`: 원본 목표 발화의 정확한 범위다.
- `source_conversation_id`, `source_group_id`, `split`: 출처와 기존 분할이다. ID·감사 메타데이터·코호트명을 모델 텍스트에 붙이지 않는다.
- `target_origin=observed_counselor_utterance`: 목표 응답은 합성 답변이나 AI의 교정문이 아니다.
- `quality_status=heuristic_screened_not_human_reviewed`: 자동 구조 검사와 보수적 후보 선별을 거쳤으며, 사람의 의미·임상 전수 검토가 아니다.

`내담자 → user`, `상담사/상담자 → assistant`로 명시적으로 매핑한다. 인접한 동일 역할의 발화만 줄바꿈 하나로 결합하며 원문 내 공백·줄바꿈은 보존한다. 첫 발화가 상담사인 상담에서도 해당 발화를 입력 맥락에 보존한다. 앞선 내담자 발화가 없는 최초 상담사 발화는 정답으로 선택하지 않는다. 실제 모델 템플릿이 이 역할 순서를 수용하는지는 학습 서버에서 토크나이저로 확인해야 한다.

각 행은 첫 원본 발화에서 해당 목표 응답까지 이어지는 접두 구간이다. 미래 발화는 포함하지 않는다. 반복된 정규화 마지막 내담자·상담사 쌍을 제거하며 validation에 존재하는 쌍은 train에서 제외한다. 인접 같은 역할의 결합은 ‘빠진 발화의 복원’이나 요약이 아니다.

## 필터와 보류

원본 1,107개 상담을 대상으로 원문·DB·기존 고정 릴리스가 일치하는지 확인한다. 필터 조건은 `manifest.json`의 `policy`와 `review/excluded_targets.jsonl.gz`에 보존한다.

- 40자 미만의 짧은 목표 응답을 제외한다. 이는 맞장구를 줄이는 휴리스틱이며, 제외된 짧은 응답이 무가치하다는 판정은 아니다.
- 설문·녹음·일정·과제 등 진행 중심 목표 응답, 약물·진단 관련 별도 검토 후보를 보류한다.
- 현재까지의 맥락에서 안전·개인정보 검토 검색어가 발견되면 그 이후 목표 후보를 보류한다. 부정·인용·과거 경험도 보수적으로 걸릴 수 있다. 검색에 걸리지 않은 사례가 모두 안전하다는 뜻은 아니다.
- 기존 검토에서 확인된 자료 수집·분류 배정 노출 216개 중 첫 노출이 나타난 뒤의 목표 후보는 보류한다. 중간 발화를 지워 문맥이 이어지는 것처럼 만들지 않는다. 첫 노출 이전의 완전한 접두 구간은 사용할 수 있다.
- 216개 목록에는 추가 검토 8개가 이미 포함돼 있다. 문서의 `turn_line`을 DB `ordinal`로 간주하지 않고 원문 `splitlines()` 누적 구간으로 연결한다.

한 후보가 여러 사유를 가질 수 있으므로 사유별 건수의 합은 제외 행 수보다 클 수 있다. 원본 DB와 이전 릴리스는 수정하지 않는다.

## 문장·단어 위치와 문맥 복원

`conversation/source_dialogues.*.jsonl.gz`는 채택된 예시를 재구성하는 데 필요한 마지막 원본 순번까지의 발화를 한 번씩 저장한다. **개별 학습 예시에 이 파일의 전체 대화를 붙이면 미래 발화가 유입될 수 있다.** 학습에는 완성된 개별 `messages`를 사용하고, 보조 조회는 해당 예시의 `target_start_ordinal` 이전으로 제한한다.

문장 `start_char:end_char`는 원발화의 Unicode code point 기준, 끝 제외다. 단어의 `start_char:end_char` 역시 원발화 기준이며, `sentence_start_char:sentence_end_char`는 별도로 계산한 문장 내부 기준이다. 두 위치에서 추출한 문자열이 원문과 동일한지 검사한다. UTF-8 바이트 위치나 모델 토큰 위치가 아니다.

단어는 원천 파이프라인의 표면 등장 단위다. 한국어 형태소나 독립 의미 단위로 보증하지 않는다. 이전 378개 단어 라벨의 불명확한 원천 연결을 새 자료에 승계하지 않고, 원본 DB의 실제 등장 건에서 출처를 재구축한다. 두 분할에 같은 표면 단어가 나타나는 것은 정상이다. 동일 상담·원천 그룹의 분할 교차와 구분해야 한다.

## 추가 감독 정보

근거 있는 감정 설명과 HOP 지원 행동은 원본 상담사 응답을 수정하지 않는 별도 AI 주석으로 관리한다. 설명에는 관측된 발화 ID와 정확한 인용 구간, 명시·잠정·근거 부족의 구분이 필요하다. 이는 짧은 근거 설명이며 모델의 숨은 사고 과정을 수집하는 작업이 아니다.

가족·친구의 언급, 부모라는 신분, 실제 주변인 지원 요청은 서로 다르다. 원문이 본인 상담이면 그 관점을 유지한다. 역할이 불명확하면 확인 또는 전이 보류를 기록한다. 추가 합성 HOP 시나리오는 합성임을 표시하고 원본 상담사 정답과 섞지 않는다. 초안 상태의 추가 주석은 기본 SFT에 포함하지 않는다.

## 학습 서버에 넘길 손실 계약

현재 산출물은 토크나이저 적용 전의 모델 공통 대화 형식이다. 서버에서는 선택한 Gemma 4의 실제 템플릿으로 전체 대화와 마지막 답변 직전 접두 구간을 각각 직렬화하고 정확한 접두 일치를 확인해야 한다. 문자 수를 토큰 수로 간주하지 않는다.

접두 구간 전체와 padding의 token label은 `-100`, 마지막 상담사 응답 구간만 토큰 정답으로 사용한다. 모든 assistant 발화를 자동으로 학습하는 일반적인 응답 전용 마스킹을 그대로 적용하면 이 계약과 다르다. 학습 길이를 초과한 예시는 임의 절단·packing 없이 보류·집계한다. 지금은 실제 모델 토크나이저 검증이나 학습을 실행하지 않았다.

공식 모델·학습 자료: [Google Gemma 4](https://ai.google.dev/gemma/docs/core), [Gemma 4 31B IT](https://huggingface.co/google/gemma-4-31B-it), [Gemma 4 12B IT](https://huggingface.co/google/gemma-4-12B-it), [Unsloth Gemma 4 학습 안내](https://unsloth.ai/docs/models/gemma-4/train). 모델·방법 선택을 기록하는 참고이며 서버 환경 설치 작업은 포함하지 않는다.

## 검증과 해석 한계

생성 과정은 원본 DB 해시와 고정 릴리스 해시, 원문 문단, 발화·문장·단어 위치를 대조한다. 배포 후 감사는 필수 파일 목록·해시·건수, 원본 접두 구간 재구성, 마지막 목표 마스크, 출처·그룹·피상담자 분할, 중복 쌍을 다시 확인한다. 해시 목록은 무결성 증거이며 출처의 진위를 독립적으로 인증하는 전자서명이 아니다.

이 결과는 원본 응답 재현 실험을 위한 데이터 형식 준비를 뜻한다. 원천 이용 조건 확인, 전문가의 의미·안전 검토, 보호자 지원 정답 확충, 실제 모델 평가·독립 테스트 세트는 완료됐다고 표시하지 않는다. 기존 `agent_training.py`의 사람·전문가 승인 경로와 운영 배포 판정은 그대로 별개로 유지한다.
