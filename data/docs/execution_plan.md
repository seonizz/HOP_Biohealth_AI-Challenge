# 실행 계획과 경계

기준: `.omx/specs/deep-interview-counseling-numeric-representations.md` (2026-10-08).

1. 전체 원천/ZIP 멤버를 해시로 목록화하고 JSON과 TXT를 대응한다. 원천은 읽기만 한다.
2. 원본 JSON 전체와 TXT를 SQLite에 보존한다. 상담·발화·문장·단어를 안정적 ID 및 원문 위치로 연결한다. 코드 사전이 없는 값은 해석하지 않는다.
3. 원래 split과 보수적인 ID/중복 그룹을 보존한다. 충돌은 격리하며 대상자 ID의 의미 확인 여부를 명시한다.
4. 학습 partition에서만 어휘·빈도·변환기를 fit한다. 기존 NumPy로 통계, 단어 count/binary/TF-IDF, 문자/단어 해싱, PPMI 및 분포 벡터를 계산한다. 전용 라이브러리·모델이 없는 형태소/신경망 임베딩은 차단 사유를 기록한다.
5. 현재 Codex가 실제 읽고 생성한 결과만 AI 실행 기록으로 수용한다. 생성과 독립 검증을 분리하고 미실행 작업은 pending, 정의 미확인은 definition_unresolved로 유지한다. 사람 검토는 실제 근거 검토를 거친 항목에 한해 분리한다.
6. AC01~AC12에 대응하여 원천 불변, 무손실 재구성, 연결/범위, 행렬 유한값, split, 재개·중복 방지를 검증한다. 전체 요구가 충족되지 않으면 부분 완료로 보고한다.

원천 데이터와 파생 결과는 Git에서 제외한다. 새 의존성 설치, 외부 AI API, 모델 다운로드, 원문 공개 없이 수행한다. 실행 환경의 알려진 모델 이름만 기록하고 정확한 모델 버전은 확인되지 않으면 null로 남긴다.
