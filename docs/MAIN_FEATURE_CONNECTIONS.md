## API 계약

| 경로 | 메서드 | 역할 |
| --- | --- | --- |
| `/api/v2/frontend/records` | POST | 원본 답변 payload를 암호화 저장. request_id로 중복 생성 방지 |
| `/api/v2/frontend/records/{project_id}/context` | POST | 원본 맥락·점수 결과 조회/저장 |
| `/api/v2/frontend/records/{project_id}/draft` | POST | 원본 가이드 생성 또는 local 모델의 초안 생성 |
| `/api/v2/frontend/records/{project_id}/guide` | POST | 가이드 조회. local 모드는 검증 통과 후만 반환 |
| `/api/v2/frontend/records/{project_id}/complete` | POST | 대화 로그·날짜·후속 질문 횟수를 검증된 가이드와 함께 기록 완성 |
| `/api/v2/frontend/records` | GET | 현재 브라우저 소유자의 완료 기록 조회 |
| `/api/v2/frontend/records/{project_id}` | DELETE | 해당 원본 기록과 암호화 payload 삭제 |

쓰기에는 JSON `request_id` UUID를 사용합니다. 인증은 기존 `hop_session` HttpOnly 쿠키와 v2 소유권·RLS 경계를 사용합니다. 서버의 원본 보기 메타데이터를 사용하므로 클라이언트가 보내는 점수 가중치나 임의 태그는 신뢰하지 않습니다. 기존 DB 마이그레이션과 다른 작업의 모델 코드는 수정하지 않습니다.
