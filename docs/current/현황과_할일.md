## 남은 결선 증거

| 항목 | 필요한 산출물 | 현재 구분 |
|---|---|---|
| 학습 목적 적합성·의미 품질 | 주변인 지원에 맞는 정답 정의, 검토자별 판정과 불일치 조정 | 자동 선별·해시 검사로 대체할 수 없음 |
| 독립 평가 자료 | 개발에 노출되지 않은 원천 그룹, 사전 기준·사용 이력 | 현재 validation은 개발 노출. 새 독립 test 미확보 |
| 실제 사용성 | 합성 과업을 사용한 실제 참여자 관찰 결과와 실패 기록 | 프로토콜만 작성. 실제 관찰 미실행 |
| 운영·현장 활용 | 보유 정책의 실제 적용, 쿠키 분실 뒤 삭제 처리, 담당자·도입처 확인 | 같은 브라우저의 직접 삭제 기능과 구분 |
| 결선 발표·제출 | 최종 공지 대조, 실제 리허설·Q&A, 제출 확인 | 파일·발표노트 준비와 구분 |
| 과제 대응 | 신청서·멘토 지침과 [과제 대응표](../competition/04_제출범위와_검증계약.md) 연결 | 승인 여부를 임의 확정하지 않음 |

완료된 결과에서 임의의 과거 질문을 바로 편집하는 기능은 아직 없다. 질문 도중 되돌리기는 지원한다. 미완료 대화는 삭제할 수 있으나 다시 이어서 진행하는 기능을 이번에 추가한 것은 아니다.

## 별도 연구 이력

사용자 확인 기준의 최종 연구 방향은 31B이며 12B는 임시 테스트 모델이다. 이 작업은 최종 체크포인트 확정·재학습·배포를 수행하지 않았다. 모델·학습·평가 상세는 [UI 정보 원칙](../../app/docs/UI_CONTENT_POLICY.md)에 따라 서비스 화면이 아닌 문서에서 관리한다.

과거 실제 모델의 성공·실패는 [재평가 v3](../competition/결선_적대적_재평가_v3.md), [수정 v4](../competition/결선_재평가_지적_수정_v4.md), [수정 v4 근거](../competition/결선_재평가_지적_수정_v4_근거.json)에 보존한다. 최종 모델 통합 여부와 처리시간은 위 결선 내부 채점의 필수 조건으로 옮겨 쓰지 않는다.
