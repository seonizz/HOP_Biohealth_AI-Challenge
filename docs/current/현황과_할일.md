## 현재 기준

G3 중복 JSON 키는 값 덮어쓰기 전에 거절하도록 수정했다. 검사기 29개, 기존 G3 7변형과 독립 5조건으로 확인했다. 후속으로 사람 검토 요청 28단위(합성 응답 24 + 별도 전문·권리 검토 4)를 내용·버전 해시에 묶고, 실제 운영 증거의 누락을 확인하는 읽기 전용 점검기를 추가했다. 두 준비 도구는 사람 승인·운영 배포를 완료하지 않는다.

**최신 가중 집중도 재검증 v11:** [대안 비교·정책 적용·실제 토큰 재검증](../competition/학습데이터_가중집중도_개선_재검증_v11.md). 2026-10-17, 사용자 선택에 따라 **419행 전부**를 보존하고 양수 가중 정책을 적용했다. train은 입력·정답 균형 성분을 절반씩 섞고 validation은 보조 가중 집계로 사용한다. **정규화 HHI 1항목·CV 5항목 악화는 가중 지표에서 해소**됐으며, 원행 지표와 무가중 primary validation은 그대로 공개한다. **정답 17,220토큰과 과업×split별 총량**, 원문·전체 맥락·기존 대표·분할을 보존했다. 실제 tokenizer에서 출력 **8,192** 및 실제 시퀀스 **4,096 이하** 조건 419/419, 관련 회귀 **125개**를 통과했다. 실제 입력 **157,668토큰**은 그대로이고 가중 입력 질량 **155,184.651**은 토큰 절감량이 아니다. 신규 사례의 상대 영향량 감소와 작은 합성 집합·사람 검토·독립 test·앱 전체 정답 부족도 기록했다. 별도 가중 손실 소비 경로를 추가했으며 모델 학습·점수 상향은 수행하지 않았다.

**보존한 실제 토큰 재검증 v10:** [토크나이저 복구·실측·집중도·적대적 검증](../competition/학습데이터_실제토큰_집중도_재검증_v10.md). 기존 서버와 SHA-256이 같은 고정 토크나이저를 로컬에 복구해 **419파생행 전부**를 새로 인코딩했다. 출력 **8,192** 예약과 실제 시퀀스 **4,096 이하** 조건 모두 통과했으며 최장 시퀀스는 **3,909토큰**이다. 전체 입력 **157,668**·정답 **17,220토큰**, 그중 신규 279행은 입력 **129,065**·정답 **12,014토큰**이다. 원문·맥락·split과 원상담 v8은 보존했다. raw HHI 18개 비교는 모두 감소했지만 정규화 HHI 1개·CV 5개 악화는 남는다. 과업별 파생 행의 재고 합계이며 자동 혼합·사람 승인·독립 test나 학습 완료를 뜻하지 않는다.

**보존한 주변인 과업 구성 v9:** [대안 비교·적용·적대적 재검증](../competition/학습데이터_주변인지원_과업정합성_개선_재검증_v9.md). 원상담 v8과 기존 주변인 20대화는 그대로 보존하고, 신규 합성 24대화·48응답을 추가해 주변인 후보를 **44대화·72응답**으로 구성했다. validation 다중턴은 **0→12대화**, 동료 관계는 **0→4대화**다. 현재 앱의 원문 관찰·reported 관계 기억 단계도 합성 12맥락에서 **24정답쌍**을 별도로 만들었다. 신규 정답은 다른 AI 검토자가 교정 후 확인했으며 사람·전문가 승인이나 독립 test가 아니다. v9 작성 당시 출력 **8,192**·유효 입력 **61,440** 계약만 적용하고 실제 토큰 길이는 미검증으로 남겼다. 해당 공백은 후속 v10의 동일 tokenizer 실측으로 해소했으며 v9 원본·manifest는 당시 상태로 보존한다. 기존 원상담의 토큰 집중도·총량·맥락·분할은 그대로이고 전체 앱 단계의 목적 정답·실제 주변인 검토는 남는다.

## 별도 연구 이력

사용자 확인 기준의 최종 연구 방향은 31B이며 12B는 임시 테스트 모델이다. 이 작업은 최종 체크포인트 확정·재학습·배포를 수행하지 않았다. 모델·학습·평가 상세는 [UI 정보 원칙](../../app/docs/UI_CONTENT_POLICY.md)에 따라 서비스 화면이 아닌 문서에서 관리한다.

과거 실제 모델의 성공·실패는 [재평가 v3](../competition/결선_적대적_재평가_v3.md), [수정 v4](../competition/결선_재평가_지적_수정_v4.md), [수정 v4 근거](../competition/결선_재평가_지적_수정_v4_근거.json)에 보존한다. 최종 모델 통합 여부와 처리시간은 위 결선 내부 채점의 필수 조건으로 옮겨 쓰지 않는다.
