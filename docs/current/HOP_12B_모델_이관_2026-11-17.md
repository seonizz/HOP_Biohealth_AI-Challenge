## 구성과 검증 방식

- `base/`: Gemma 4 12B IT 기본 가중치·설정·토크나이저.
- `adapters/selected/`: 기존 학습 출력의 `selected` 어댑터. A 답변·상태 기억, B 대화·최종 검토 및 공통 학습 선택본.
- `adapters/final-runs/`: 후속 실험의 `work/train/adapter` 최종 저장본. 저장은 운영 승격이나 품질 승인과 구분한다.
- `adapters/A_original/`: 기존 A 원본 어댑터.
- `gguf/`: Mac에 있는 12B IT Q8 기본 모델과 A 원본 GGUF 어댑터.

중간 `checkpoint-*`, optimizer 상태, 학습 데이터, 평가 원문, Ollama 모델은 복사 대상에서 제외한다. 파일별 원본 경로·크기·SHA-256을 `MANIFEST.json`에 기록한다. Ubuntu 모델을 NAS에 복사한 뒤 다시 읽어 SHA-256을 확인하고, Mac에서 NAS 패키지를 GPU 서버로 전송한 뒤 서버에서 모든 모델 파일을 다시 해시한다. 기존 파일을 덮어쓰지 않도록 신규 보관 디렉터리의 부재를 먼저 확인한다.

모델·가중치·실행 증적은 Git에서 제외된 경로에 둔다. 이 문서는 경로와 검증 요약만 기록한다.
