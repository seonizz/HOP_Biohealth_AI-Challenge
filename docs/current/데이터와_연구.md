# 데이터와 연구

현재 서비스의 동작은 [관계 에이전트 기술 문서](../../app/docs/RELATIONSHIP_AGENT.md), 데이터 처리 명령과 파일 계약은 [데이터 README](../../data/README.md)에 둡니다. 이 문서는 서로 다른 데이터·실험을 구분하는 기준입니다.

모델 진행 방향은 [현황과 할 일](현황과_할일.md#모델-진행-방향)을 따릅니다. 31B가 최종 목표이며 12B는 현재 임시 테스트에 사용합니다. 아래 31B 수치는 기존 부분학습 기록으로, 전환 완료나 최종 모델 품질을 뜻하지 않습니다.

## 저장된 실험 결과

- 상담 분류 기준 모델은 TF-IDF + Naive Bayes이며 저장된 Validation Macro F1은 **0.5535**입니다. 동작 확인용 기준점으로, 독립 test·사람 단위 일반화 검증이 아닙니다. [분류 결과](../../data/데이터셋/학습용_3종_v1_20261009/baseline_smoke.json)
- 31B는 예정 5,052 optimizer step 중 **100 step·800행**까지 학습한 기록입니다. 고정 검증 32행·정답 2,905토큰의 NLL은 **4.685542 → 2.922296**입니다. 분류 성능이나 상담 품질 향상률로 해석하지 않습니다. [학습 기록](../../ai/outputs/dualgpu_maxctx_20261009/STOP_AND_API_HANDOFF.md)
- 31B의 요청 예산·접속 방법은 [31B API 이용 안내](../../ai/trained_model_api/LOCAL_USAGE_REFERENCE.md)를 기준으로 확인합니다. 과거 128K 입력 실측을 현재 운영 예산이나 장문 이해 품질로 재사용하지 않습니다. 서버의 실시간 상태는 별도 확인이 필요합니다.
- 공개 합성 출력의 종료·형식 비교는 [발표 데이터 기록](../../presentation/outputs/presentation_collection_FT31_STEP100_20261009T192608Z/comparison.md)에 있습니다. 요청 조건과 과제가 다른 실행을 모델 우열의 증거로 합치지 않습니다.

## 사용 계약

원본·파생 라벨·원문 위치·출처와 검토 이력을 분리합니다. 문장·단어 위치는 Unicode code point의 끝 제외 범위이며 상담 전체 라벨을 자동으로 하위 문장·단어 정답에 복제하지 않습니다. SFT는 원문과 최종 assistant 응답의 학습 역할을 구분합니다. 구체적인 직렬화·손실 마스크는 해당 [SFT 계약](../../data/docs/support_agent/말씨_원본상담_SFT_데이터계약_2026-10-09.md)을 따릅니다.

파일 해시·토큰 배열·JSON 형식 검증 통과는 의미 정확도, 권리 승인, 임상 타당성, 모델 학습 완료를 뜻하지 않습니다. 원천 JSON·정책·fixture·평가 산출물은 증거로 보존하며, 오래된 `implemented=false` 같은 연구 메타데이터를 현재 앱 전체의 구현 상태로 해석하지 않습니다.
