# 데이터 설계·분석 방법과 평가 계획

2026-11-19 사용자 제공 설명을 기준으로 정리했습니다. 데이터 구성 방법과 향후 평가 목표를 구분합니다. 아래 목표는 측정 결과나 달성한 성과가 아니며, 이 문서 추가로 학습·평가를 실행한 것은 아닙니다.

## 데이터 설계·분석 방법

실제 심리상담에서 내담자와 상담사가 나눈 대화를 화자와 발화 순서에 맞춰 정리했습니다. 내담자가 설명한 상황과 이전 상담사 응답을 입력으로 사용하고, 다음 상담사가 실제로 한 말을 정답으로 구성했습니다. 단순하거나 맥락이 부족한 대화는 제외했습니다.

말씨 서비스에 필요한 데이터는 다음 목적에 맞춰 별도로 구성했습니다.

- 질문이나 대화 내용을 보고 상황에 맞는 다음 질문을 선택합니다.
- 대화에서 나온 인물 관계와 상황을 정리합니다.
- 앞뒤 내용이 달라지거나 잘못된 답변이 나왔을 때 오류를 파악하고 다시 질문합니다. 예를 들어 아버지 이야기가 갑자기 동생 이야기로 바뀔 때, 대상이 바뀐 것인지 확인하는 경우를 다룹니다. 대상 변경 자체를 오류로 단정하지 않습니다.
- 근거 없는 답변을 줄이기 위해 대화에서 실제로 나온 사실을 확인하고 해당 내용을 정확하게 인용하는지 평가합니다.
- 잘못된 안내 내용을 찾아 수정하고 상황에 맞는 최종 안내 카드를 만듭니다.

이는 사용자가 제공한 데이터 구성 설명입니다. 특정 상담기법의 명칭이나 임상적 효과, 현재 운영 모델의 학습 완료를 추가로 주장하지 않습니다. 실제 상담 원문·학습 데이터는 이 문서에 포함하지 않습니다.

## 향후 평가 기준과 목표안

해당 기준으로 평가할 예정입니다. 기준 모델 대비 개선과 절대 목표를 구분하며, 결과는 평가 후 별도로 기록합니다.

| 핵심 기준 | 평가 내용 | 주요 수치와 목표안 |
|---|---|---|
| 질문 판단의 정확성 | 이미 답한 질문이나 불필요한 질문은 생략하고, 필요한 질문은 유지하는가 | 질문 판단 Macro F1이 기준 모델보다 0.05 이상 개선 |
| 사실과 맥락의 정확성 | 사람·관계·시점·부정·정정 내용을 정확히 반영하는가 | 사실 추출 Micro F1이 기준 모델보다 0.05 이상 개선 |
| 검토 능력 | 잘못된 초안을 올바른 이유로 반려하고, 정상 초안은 보존하는가 | 근거일치 오류 검출률 90% 이상, 정상 초안 처리 실패율 10% 이하 |
| 현재 위험 판단 | 입력에 명시된 현재 위험을 놓치거나 과도하게 판단하지 않는가 | 양성 재현율 95% 이상, 음성 정상 처리율 90% 이상 |
| 최종 안내의 충실성 | 원문에 없는 사실이나 생략된 답변을 만들어 내지 않는가 | 평가자별 충실성 등 필수 적합률 90% 이상, 중대 오류 관측 0건 |
| 안내의 유용성 | 사용자의 목적과 상황에 맞고 실제로 사용할 수 있는가 | 두 평가자가 1~5점으로 채점하고 기준 모델 대비 개선 확인 |

평가를 실행하기 전에는 기준 모델, 평가 자료·표본 수, 각 지표의 분모, 필수 적합 항목과 중대 오류의 정의를 확정해야 합니다. 이 문서는 목표를 기록하며, 아직 정해지지 않은 조건이나 관측 결과를 임의로 채우지 않습니다. 중대 오류 관측 0건은 평가 표본에서 확인할 목표이며 모든 이용 상황에서 오류가 없다는 보장이 아닙니다.
