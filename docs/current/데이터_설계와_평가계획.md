# 데이터 설계·분석 방법과 평가 계획

2026-11-19 사용자 제공 설명을 기준으로 정리했습니다. 데이터 구성 방법, Git에 남아 있는 완료 평가, 사용자 제공 진행 중 평가, 향후 목표를 구분합니다. 목표는 달성한 성과가 아니며 이 문서 갱신으로 학습·평가를 실행한 것은 아닙니다.

## 데이터 설계·분석 방법

실제 심리상담에서 내담자와 상담사가 나눈 대화를 화자와 발화 순서에 맞춰 정리했습니다. 내담자가 설명한 상황과 이전 상담사 응답을 입력으로 사용하고, 다음 상담사가 실제로 한 말을 정답으로 구성했습니다. 단순하거나 맥락이 부족한 대화는 제외했습니다.

말씨 서비스에 필요한 데이터는 다음 목적에 맞춰 별도로 구성했습니다.

- 질문이나 대화 내용을 보고 상황에 맞는 다음 질문을 선택합니다.
- 대화에서 나온 인물 관계와 상황을 정리합니다.
- 앞뒤 내용이 달라지거나 잘못된 답변이 나왔을 때 오류를 파악하고 다시 질문합니다. 예를 들어 아버지 이야기가 갑자기 동생 이야기로 바뀔 때, 대상이 바뀐 것인지 확인하는 경우를 다룹니다. 대상 변경 자체를 오류로 단정하지 않습니다.
- 근거 없는 답변을 줄이기 위해 대화에서 실제로 나온 사실을 확인하고 해당 내용을 정확하게 인용하는지 평가합니다.
- 잘못된 안내 내용을 찾아 수정하고 상황에 맞는 최종 안내 카드를 만듭니다.

데이터 분석에서는 중복·누락, 길이와 과업별 분포를 점검하고 같은 사례가 학습과 검증 자료에 동시에 들어가지 않도록 분리했습니다. 별도 분류 실험에는 TF-IDF와 Naive Bayes를 사용했습니다.

이는 사용자가 제공한 데이터 구성 설명입니다. 특정 상담기법의 명칭이나 임상적 효과, 현재 운영 모델의 학습 완료를 추가로 주장하지 않습니다. 실제 상담 원문·학습 데이터는 이 문서에 포함하지 않습니다.

## 향후 평가 기준과 목표안

해당 기준으로 평가할 예정입니다. 기준 모델 대비 개선과 절대 목표를 구분하며, 결과는 평가 후 별도로 기록합니다.

| 핵심 기준 | 평가 내용 | 주요 수치와 목표안 |
|---|---|---|
| 질문 판단의 정확성 | 이미 답한 질문이나 불필요한 질문은 생략하고, 필요한 질문은 유지하는가 | 질문 판단 Macro F1이 기준 모델보다 0.05 이상 개선 |
| 사실과 맥락의 정확성 | 사람·관계·시점·부정·정정 내용을 정확히 반영하는가 | 사실 추출 Micro F1이 기준 모델보다 0.05 이상 개선 |
| 검토 능력 | 잘못된 초안을 올바른 이유로 반려하고, 정상 초안은 보존하는가 | 근거일치 오류 검출률 90% 이상, 정상 초안 처리 실패율 10% 이하 |
| 현재 위험 판단 | 입력에 명시된 현재 위험을 놓치거나 과도하게 판단하지 않는가 | 양성 재현율 95% 이상, 음성 정상 처리율 90% 이상 |
| 최종 안내의 충실성 | 원문에 없는 사실이나 생략된 답변을 만들어 내지 않는가 | 평가자별 충실성 등 필수 적합률 90% 이상, 중대 오류 관측 0건 |
| 안내의 유용성 | 사용자의 목적과 상황에 맞고 실제로 사용할 수 있는가 | 두 평가자가 1~5점으로 채점하고 기준 모델 대비 개선 확인 |

평가를 실행하기 전에는 기준 모델, 평가 자료·표본 수, 각 지표의 분모, 필수 적합 항목과 중대 오류의 정의를 확정해야 합니다. 이 문서는 목표를 기록하며, 아직 정해지지 않은 조건이나 관측 결과를 임의로 채우지 않습니다. 중대 오류 관측 0건은 평가 표본에서 확인할 목표이며 모든 이용 상황에서 오류가 없다는 보장이 아닙니다.

## 소개 화면과의 연결

소개 화면의 기존 02번 구간과 펼침 항목에 대화의 흐름, 필요한 질문, 사실 확인, 평가 계획을 쉬운 말로 요약합니다. 공개 데이터 통계는 출처의 수량으로 유지하며 말씨가 별도로 구성한 데이터의 수량·학습량으로 해석하지 않습니다. 지표명과 목표 수치는 이 문서에 보관합니다. 후속 사용자 요청에 따라 완료된 평가의 주요 관측값과 진행 중 평가의 구성은 홈페이지 펼침 항목에도 조건·한계와 함께 표시합니다.

03번 질문 안내는 [질문셋 v3.1](../../app/docs/QUESTIONNAIRE_V3_1.md)을 따릅니다. 이 설명 반영은 질문셋·서버 로직·질문 생략 동작을 변경하지 않습니다.


## 추가 학습과 완료된 비교 평가

사용자 제공 설명에 따르면 Gemma 4 31B 기반의 4비트 양자화와 LoRA를 사용했습니다. 기존 가중치를 고정하고 일부 파라미터를 학습하며, 상담 응답 생성에서 질문 선택·관계와 사실 파악·오류 확인·근거 확인·카드 수정 및 생성으로 자료와 학습 범위를 확장했습니다. 학습·데이터 가공에 집중했던 예선 이후, 본선 준비에서는 출력 안정성과 근거 없는 내용의 생성을 줄이는 방향으로 보완했습니다.

Git에 남아 있는 [11월 15일 완료 평가](../../ai/docs/review_approval_bias_repair.md#31b-step4723--step5128)는 **step4723과 step5128**의 비교입니다. 원본 31B와의 비교가 아닙니다. 동일 입력·생성 조건의 1,080개 입력은 20개 원천 사례의 변형이며 독립적인 실제 상담 1,080건이 아닙니다.

| 지표 | step4723 | step5128 |
|---|---:|---:|
| 정상 초안 승인 | 170/360 (47.2%) | 360/360 (100.0%) |
| 오류 초안 거절 | 247/360 (68.6%) | 353/360 (98.1%) |
| 오류 필드·actual/expected 정확 일치 | 4/360 (1.1%) | 285/360 (79.2%) |
| 상태 전체 사실 정확 일치 | 136/360 (37.8%) | 196/360 (54.4%) |

승인·거절은 원문 기록의 거절/승인 건수와 무효 출력 건수에서 계산했습니다. 정상 승인: (360−171−19)/360 → (360−0−0)/360. 오류 거절: (360−96−17)/360 → (360−6−1)/360. 무효 출력을 성공으로 합치거나 분모에서 빼지 않았습니다.

완료 보고의 최종 판정은 `insufficient_joint_quality`입니다. 일부 지표 개선은 확인됐지만 사실 전체 정확도 등 종합 기준을 충족하지 못했습니다. 실제 서비스 정확도·임상 효과나 배포 승인을 입증한 수치가 아닙니다.

## 원본 31B와 step5128의 추가 평가 — 진행 중

2026-11-19 사용자가 제공한 진행 상황입니다. 이번 웹 수정에서 실행 상태·완료 산출물을 별도로 검증한 것은 아니며, 앞의 완료 평가와 구분합니다. 점수와 개선 여부는 완료 후 확정합니다.

- 자체 평가: 모델당 336개 입력. 정상 초안의 불필요한 거절, 오류 초안의 승인, time 필드, 최신 정보·부정·확실성·정정, 오류 필드 및 수정 근거를 확인합니다.
- 질문 판단 Macro F1, 사실 추출 Micro F1, 반복 질문·부당 생략·미응답 정보 생성·지원 정책·JSON 규격 준수도 확인합니다.
- ARC-Challenge 200문항과 ARC-Easy 200문항: 고정한 동일 문항에서 선택지 로그확률로 답을 선택합니다.
- 총 모델당 736개, 두 모델 합계 1,472개. 자체 평가와 ARC를 한 종합 점수로 합치지 않습니다.
- 산출 계획: 지표별 점수·변화량, 유형별 실패, ARC 정확도·길이 보정 정확도·95% 신뢰구간, 요청별 시간 통계, 문항 ID·입력 토큰·선택지 점수·실행 설정·해시.

ARC는 각 200문항의 부분집합 점수이며 공식 전체 시험 점수가 아닙니다. 영문 과학 지식·추론 평가가 한국어 상담 품질이나 실제 유용성을 직접 입증하지 않습니다. 사람의 의미·품질 평가와 앱 전체 이용 완료율·처리시간 측정은 이번 실행에 포함하지 않습니다. 앞의 평가자별 품질·유용성 목표는 별도 향후 계획입니다.
