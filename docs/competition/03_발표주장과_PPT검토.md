## PPT 내용 검사 결과

`presentation/slides`의 **32개 PPTX / 60개 슬라이드** 텍스트를 확인했습니다. 원본 PPT를 변경하지 않았으며 레이아웃 시각 검사는 이번 범위가 아닙니다.

- 14개 덱의 본문에 `37.6`이 있습니다. 연구근거 덱의 노트는 NLL 조건을 설명하지만 슬라이드 본문의 `+37.6% 학습 지표 개선`만으로는 실제 서비스 품질 향상으로 오해할 수 있습니다.
- 3개 덱에 90%·95%가 함께 있으며 선행연구의 평가자 일치도라고 표시되어 있습니다. 말씨 자체 점수로 재해석하지 않습니다. 논문 결과 자체를 이번 작업에서 새로 검증한 것은 아닙니다.
- 전체 덱의 슬라이드 본문에서 `12B` 표기는 없습니다. 임시 12B 테스트 단계와 목표 31B 전환 계획을 함께 설명해야 합니다.
- 기대효과 덱에는 49.4%, 71.8%, 61.7%, 110만 명 등이 있으나 확인한 설명초록색 버전의 노트는 사용자 제공 PPT만 출처로 적습니다. 원조사·연도·대상·분모 확인 전에는 검증된 시장 통계로 확정하지 않습니다.
- 결선 로드맵의 전처리 연구, 상담사 답변 비교, 사용자 의견 확인은 계획 항목입니다. 완료된 실험 결과로 바꾸지 않습니다.

## 발표 구성 제안

이 순서는 공식 장수 제한이 아니라 현재 증거를 설명하기 위한 제안입니다.

1. 대회 문제와 데이터: 상담 대화 판별 과제, 데이터 출처·선별 흐름.
2. 판별 방법: 목표 라벨, 상담 단위 입력, 비교 모델과 분할 정책.
3. 판별 결과: 기준 모델, 클래스별 성능·혼동·실패 사례, 미검증 한계.
4. 말씨의 응용 가치: 주변인 지원에서 어떤 정보를 활용하고 무엇을 판단하지 않는지.
5. 현재 테스트 시연: 임시 12B 관계 에이전트의 원문 근거·말하기·행동·자기돌봄.
6. 목표 모델 준비: 31B SFT·NLL 기록과 전환·평가 계획, 질환 분류 성과와 구분.
7. 다음 검증과 실행 계획: 독립 평가·사람 검토·서비스 완주·역할 분담.

현재 분류 기준 모델이 웹에서 실제 호출된다는 근거는 확인하지 않았습니다. 위 흐름을 이미 연결된 시스템처럼 그리지 말고 구현된 부분과 연결 계획을 표시해야 합니다.
