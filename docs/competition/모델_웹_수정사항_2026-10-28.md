# 모델·웹 수정사항

작성일: 2026년 10월 28일

기존 적대적 평가에서 지적한 모델 안전 경계 2건과 웹 결함 2건을 수정했다. 기존 카드 디자인과 문맥에 따른 질문 생략 기능은 유지했다. 이 문서는 완료된 수정과 검증 기록을 정리한 것으로, 문서 작성 과정에서 검사를 새로 실행한 것은 아니다.

## 2. 재검증 중 추가로 보완한 항목

- **질문 생략 ID 중복:** 중복을 질문 블록 내부에서 거절하고 해당 블록을 재작성하도록 했다. 근거 있는 생략은 유지하며, 생략한 질문의 답변이나 사실을 생성하지 않는다. 중복이 계속되면 결과를 수용하지 않는다.
- **관계 분석 JSON 구조:** 실제 모델이 `strengths`와 `boundaries`를 잘못된 최상위 위치에 출력한 문제에 대응해 `relationship.strengths`, `relationship.boundaries`의 위치를 프롬프트에 명시했다. 검증 스키마를 완화하지 않았다.
- **이전 형식 기록:** 오래된 저장 context 대신 현재 intake에서 문맥을 다시 구성해 안전 승인 정보가 누락되지 않게 했다. 원문 지문이 없는 과거 승인은 최종 단계에서 재검토한다.
- **삭제 후 화면 상태:** 삭제된 기록의 목록 잔상과 이전 삭제 요청이 다른 대화의 새 확인창에 영향을 주는 문제도 함께 보완했다.

## 3. 유지한 기능과 디자인

- 앞선 답변의 맥락에 따라 아직 직접 답하지 않은 질문도 생략할 수 있다. 생략을 답변으로 저장하거나 최종 카드의 사실 근거로 사용하지 않는다.
- 돌봄 카드의 연한 초록 배경, 왼쪽 마스코트, 공감 문단과 작은 도움말을 유지했다.
- 대화문 카드의 크림색 배경, 초록 점선 테두리, 전체 발화 문단과 오른쪽 위 복사 버튼을 유지했다.
- 실천·회피 카드는 넓은 화면에서 나란히, 좁은 모바일 화면에서 한 열로 표시한다.
- 기존 진행바와 점 세 개 대기 표시를 유지했다. 카드 렌더링·CSS 파일의 해시는 작업 시작 시점과 동일하다.

## 6. 적대적 재평가와 적용 범위

**기존 P1 2건과 P2 2건은 재현한 반례 범위에서 수정 검증 통과로 판정한다.** 전체 모델 생성 신뢰도는 조건부다. 소수의 개발용 합성 사례와 재작성 이력만으로 새로운 입력 전반의 정확성이나 실사용 안전성을 입증할 수는 없다. 웹 역시 다른 브라우저 엔진과 스크린리더 조합까지 검증한 것은 아니다.

처리시간은 평가하지 않았다. 기존 결선 총점 53/90은 이번 기술 검증으로 다시 계산하지 않았다.

이번 결과는 별도 로컬 검증 인스턴스 기준이며, **기존 9001 서비스 프로세스는 재시작하지 않았다.** 기존 사용자 기록과 Git 스테이징을 보존했다. GPU 서버에 접근하지 않았고, 검증에 사용한 임시 앱·DB·브라우저 탭은 정리했다.
