## 3. 대안의 실제 비교와 적용 정책

**짧은 5행·긴 4행 교체안을 적용했다.** 짧은 후보에서는 통과한 3행안보다 2행을 더 바꾸면 입력과 플래그 수의 v5 이후 증가까지 회수할 수 있었다. 긴 후보는 v6 상한을 충족하는 안을 선택했다. 두 후보의 cap 기준은 설정에 명시해 고정했다. 공통 입력 집중도 기준은 모두 더 엄격한 **v7**이며, 셀별 신규 플래그 금지는 모두 **v6** 기준이다.

더 강한 긴 후보의 v5 상한은 단일 교체 경로에서 validation 입력 +276토큰과 집중도 2지표를 해결하지 못했다. 이어 서로 다른 두 validation 셀의 조합 **226개를 단계당 검사하고 최대 3단계**까지 탐색했다. 두 쌍을 적용한 뒤에도 +239토큰이 남고 공동 조건을 통과하지 못해 적용하지 않았다. v6 입력 총량을 split별 **정확히 같게** 만드는 비교에서는 짧은 7행안이 통과했지만 감소 개선이 있는 5행안보다 교체가 많았다. 긴 후보의 동일 총량 경로는 통과하지 못했다. 이는 정해진 경로의 실패이며 전체 대안의 불가능성이나 적용안의 전역 최소 교체 수를 뜻하지 않는다.

적용한 선택 절차는 다음과 같다.

1. v7의 선택 셀·정답 길이·후기 ID를 기준으로 대체 가능 원행을 고정한다. v6에서 절차성 플래그가 없던 셀에는 플래그가 있는 원행을 허용하지 않는다. 후기 대표는 고정한다.
2. v6의 선택에서 시작한다. 정확한 분수로 v7 입력 집중도 초과분, 프로파일별 split 입력 상한 초과분, 플래그 수 상한 초과분의 상대 제곱 합을 계산한다.
