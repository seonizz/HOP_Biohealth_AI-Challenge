## A2. [P3] 보이지 않는 문자만으로 필수 답변을 통과한다

**판정: 현재 코드에서 재현된 입력 완결성 결함, 확신도 높음.** UI와 서버는 `trim()` 및 정확한 건너뛰기 표시 문자열 비교로 빈 입력을 판정한다. 이 방식은 U+200B ZERO WIDTH SPACE 같은 문자만 있는 입력을 비어 있다고 처리하지 않는다. 필수 후속 답변은 이미 존재하는 기본 답변에 병합되므로 답변 수가 추가 증가하지 않는다. 후속 원문 저장과 출처 편입은 확인했다. 이를 기본 답변과 같은 ‘답변 수 +1’로 보고하지 않는다. NUL의 화면 입력·렌더링은 확인하지 않았으며 직접 HTTP 경계로 한정한다.
