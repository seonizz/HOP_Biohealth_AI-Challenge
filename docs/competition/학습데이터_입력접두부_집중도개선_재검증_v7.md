## 1. 악화 원인과 성공 조건

v6는 전기 대표의 정답 길이가 상쇄되는 쌍을 골라 그룹별 **정답 토큰** 집중도를 개선했다. 같은 원상담의 다른 시점으로 대표를 바꾸면 그 정답까지의 전체 접두부 길이도 달라진다. 정답 토큰의 상쇄는 접두부 토큰의 상쇄를 보장하지 않으므로 입력 집중도는 별도 조건이 필요하다.

입력 집중도는 그룹별 `P_g=Σ 선택행의 prefix_length`, 전체 `P=ΣP_g`로 계산한다. 상위 5·10그룹의 `P_g/P` 합과 `HHI=Σ(P_g/P)²`를 train·validation·전체에서 각각 검사한다. 같은 과거 문맥이 여러 행에 반복되면 반복해서 센다. 고유 원문량이나 감독 정답 토큰, 실제 학습 손실 가중치와 다른 단위다. 그룹 순위도 정답 토큰 순위를 재사용하지 않고 접두부 합으로 다시 정한다.

## 3. 적용 정책

v6에서 선택된 각 상담×구간 셀을 고정한다. 전기 셀만 같은 원래 split·그룹·상담·구간의 적격 원행 중 **v6 대표와 정답 토큰 길이까지 같은 행**으로 바꿀 수 있다. 후기 대표는 v6 ID 그대로다. 따라서 셀별 정답 길이, split·그룹별 정답 합, 정답 길이 분포와 정답 집중도는 정확히 유지된다.

각 단계에서 다음 조건을 모두 만족하는 원행만 후보로 인정한다.

1. split 입력 총량은 최초 v6 총량의 **±0.2%** 이내다. 반올림 없이 `|새 총량−v6 총량|×500≤v6 총량`을 검사한다.
2. train·validation·전체의 접두부 상위 5·10그룹 비중과 HHI **9개 모두 직전 단계 이하**다. 단일 교체는 분모가 달라지므로 정확 상쇄 쌍의 수학적 보장 대신 매번 정확한 분수로 재계산한다.
3. 지표별 `min(v5,v6)`를 한계로 둔 초과량 제곱합 `Σ max(0, 지표/한계−1)²`이 엄밀히 감소한다. 9지표가 모두 통과한 최초 단계에서 멈춘다.
4. 동률은 초과 점수, 최초 v6 대비 추가 변경 대표 수, 접두부 변화 절댓값, 현재 대표 대비 정규화한 정답 순번 거리, 고정 seed 순서로 해소한다. 조건을 만족하는 이동이 없으면 실패하고 제약을 자동 완화하지 않는다.

**±0.2%와 단계별 비악화는 이번 개발 탐색에서 선택한 보수적 정책**이며 사전에 등록한 결선 기준이나 임상적 허용치가 아니다. 입력 길이의 소폭 증가를 허용하는 대신 교체를 적게 하고 정답 노출량을 정확히 고정한다. 이 경로는 전역 최소 교체 수·최적 의미 보존을 증명하지 않는다. 원래 검토·보류와 사람 미승인 상태도 그대로 유지한다.
