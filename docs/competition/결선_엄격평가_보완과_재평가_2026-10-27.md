# 결선 엄격 평가의 보완과 재평가

기준일: 2026-10-27, Asia/Seoul. 사용자의 요청에 따라 지적 사항 가운데 현재 로컬에서 처리할 수 있는 보완을 적용하고, **직전 엄격 평가와 동일한 기준으로 50→53/90점**으로 재평가했다. 현장 발표·Q&A 10점은 관찰하지 않아 유보한다. 공식 심사 결과나 수상 가능성의 확률 예측은 아니다.

현재 증거는 구현과 검증 절차를 설명하는 데는 충분하지만, 사용자가 대안을 두고 말씨를 선택하는 이유와 현장 효용·기관 도입을 입증하지 못한다. 문서와 검사 수가 늘었다는 이유로 그 빈칸에 점수를 주지 않았다.

## 1. 채점 기준을 고정한 재평가

첨부 운영계획(안)의 결선 30·20·30·20 틀과 [사용자 지정 평가 범위](05_평가범위와_학습데이터_기준.md)를 따른다. 모델 자체의 성능·크기·학습 진행·생성 품질·로딩·앱 통합과 처리시간은 채점에서 제외한다. 공식 모델 항목을 학습 데이터로 대체한 것은 내부 평가 방식이며 주최 측 규정의 변경이 아니다. 앱의 입력·출처·저장·삭제·격리 계약은 별도로 평가한다.

## 3. 데이터 보완의 정확한 의미

기준 묶음은 `training_data/two_stage_training_20261022`다. 원상담 **40,701** + 주변인 보정 **72** + 서비스 JSON **156** + 보조 과업 **347** = **41,276행**이다. 행은 파생 학습 단위이며 독립 사람·사례 수가 아니다. 원본 파일·기존 split·원천 그룹을 바꾸지 않았다.

원천 manifest SHA-256:

```text
1e35389c6efd5ac51645fda583bf597b4af69864e3a1dfd777372efafa9871d1
```

서비스 validation 33행 중 28행에서 train 정답과 NFKC·공백 정규화 후 연속 200자 이상 일치가 재현됐다. 검출한 행의 식별 집합은 10월 23일 감사와 같고 가장 긴 일치 구간은 정답 길이의 47.1~88.2%다. 전체 정답 완전 일치는 0이다. JSON 구조와 공통 안내 문구도 포함되므로 이를 같은 사람·상담 사례나 개인정보 유출의 증거로 단정하지 않는다. 의미상·비연속 중복이나 train 입력 전체와의 비교를 새로 수행한 결과도 아니다.

28행을 제외한 5행 역시 개발에 노출됐으며 독립성이 증명되지 않았다. 두 부분 모두 독립 test 용도를 거절한다. 형식 회귀·개발 비교·검토 대기 용도만 허용한다. 이 제한은 새 CLI의 판단 계약이며 원본 소비 경로 전체를 바꾸지는 않았다. 개발 노출을 지운 것처럼 이름만 바꿔 test를 만들지 않는다.

현재 검토 준비물은 Git 제외 경로 `training_data/final_review_20261027_r2/`다. 주변인 72 + 서비스 156 = 주 과업 228행, 보조 347행을 합쳐 **575행 전부**를 포함한다. 입력만 보는 자료·정답 자료·판정 양식·진행 안내를 원천 내용 해시와 연결했다. 실제 승인 0, 임상·사람 승인 false, 독립 test false다. 원상담 40,701행과 기존 전문 보류 4건은 이 575행에 포함하지 않는다.

최종 r2 검토 manifest pin:

```text
3de211891c45312bb0674ee2ab5d6e94ff6af511cb92a028d02e188f7cda4ebf
```

독립 검토에서 검사기 경로 오류를 고치면서 준비 코드의 해시가 바뀌었다. 이전 r1은 보존하고 r2를 별도 생성·검증했다. 예전 `cc28…` pin을 새 코드의 검증 근거로 사용하지 않는다. 준비물 검증은 사람의 신원·판정·권리·허용 범위를 인증하지 않는다.

```sh
python3 -B -m unittest discover -s ai/scripts -p 'test_audit_final_validation.py' -v
python3 -B ai/scripts/audit_final_validation.py verify-review \
  --root training_data/two_stage_training_20261022 \
  --review training_data/final_review_20261027_r2 \
  --expected-review-sha256 3de211891c45312bb0674ee2ab5d6e94ff6af511cb92a028d02e188f7cda4ebf
python3 -B ai/scripts/audit_final_validation.py gate \
  --root training_data/two_stage_training_20261022 \
  --purpose independent_test --subset no_long_match_detected
```

마지막 명령은 허용되지 않는 승격을 검사하므로 **거절·종료 2가 기대 결과**다. 허용된 개발 사용과 독립 test의 구분은 `data/summary.json` 및 용도별 gate 결과에서 확인한다. 새 원문·정답 준비물은 Git에 추가하지 않았다.

숫자들은 서로 다른 단위다. 합계 검사 수를 하나의 성공률·독립 사례 수로 제시하지 않는다. 앱 검사는 모델과 분리 가능한 입력·정정·저장·삭제·격리 계약의 근거다. 테스트 실행 모델은 합성 fixture이므로 모델 성능·학습 데이터 품질의 대체 근거로 사용하지 않는다.

독립 코드 검토에서 새 도구의 결함 두 건을 찾아 수정했다.

1. **DB 접속 제한 우회:** `pg`는 URL query의 host·port·user를 접속 주소로 해석할 수 있었다. query·fragment·다른 프로토콜·사용자·DB·주소를 거절하고 허용 값으로 URI를 재구성했다. Docker·DB 접근 전에 검사하며 실제 `pg` parser와 대조했다.
2. **검토팩 경로의 무한 루프:** 정규화 전 `..`가 포함된 절대 경로에서 부모 순회가 저장소에 도달하지 못했다. 비정규 경로를 먼저 거절하고 루트 종료 방어를 추가했으며 CLI의 원본 경로 문자열도 보존해 검사한다.

독립 검토자는 수정 후 관련 회귀와 문법·AST 검사를 다시 통과시켰고, 검토한 9개 파일에서 남은 재현 결함을 발견하지 못했다. 형식적 보안 인증이나 전체 저장소 무결함 선언은 아니다. LSP/ast-grep 검사는 도구 부재로 수행하지 않았다. 허용된 Ollama에는 내부 자료 없는 일반 질문으로 접속을 시도했지만 연결 시간 초과로 보조 의견을 얻지 못했다.

실행 기록은 `runtime/finals-remediation-20261027/`에 있다. `app-tests.log`, `data/summary.json`, `comparison/parent-result.json`, `operations/restore-rehearsal.json`, `presentation/final-validation.json`, `preservation-check.json`, `final-evidence-manifest.json`을 구분해 보관한다.

| 도입·확장 | 대상·장면·역할·비용 항목별 제안 | 기관 회신·담당자·예산·시범 사용·채택 근거 |
| 대회 범위·제출 | 공식 모집 자료와 첨부 운영계획 대조 | 최종 제출 안내, 신청서·멘토 기록과 서비스 범위의 연결, 실제 발표·Q&A |

기관이나 검토자에게 메시지를 보내거나, 실제 사람을 관찰한 것처럼 기록하지 않았다. 모집 신청서의 10쪽 제한은 모집 양식에 관한 것이며 결선 PPT 규격으로 사용하지 않는다. 운영계획의 질환 판별 주제와 주변인 지원 서비스의 관계는 확인이 남아 있지만 부적격으로 단정하지 않으며 모델 통합 여부의 간접 감점으로도 사용하지 않는다.

## 6. 변경물과 보존 범위

- 데이터 도구: `ai/scripts/audit_final_validation.py`, `ai/scripts/test_audit_final_validation.py`.
- 비교 도구: `tools/final_workflow_comparison.mjs`, `tools/test_final_workflow_comparison.mjs`.
- 복원 검증 도구: `tools/rehearse_final_operations.mjs`, `tools/final_rehearsal_connection.mjs`, `tools/test_final_rehearsal_connection.mjs`.
- 문서: 이 평가서, 대안 비교 보강 문서, 운영·도입 실행팩, 루트·대회·발표 README의 최신 진입점.
- 발표: `presentation/final/말씨_결선_실전발표_v6_검수본.pptx`와 같은 이름의 `.json` 내용·노트.

앱 기능·화면·카드 디자인·문맥에 따른 질문 생략 정책은 바꾸지 않았다. 기존 데이터·split과 v5까지의 발표본을 보존했다. GPU 서버에 접속하지 않았고, 기존 서비스 DB 대신 이 작업 소유의 일회용 DB만 사용했다. 커밋·푸시·기존 스테이징 변경을 하지 않았다. 검토 원문은 Git 제외 로컬 경로에 두며 공개 문서에는 집계·방법·해시·한계만 적었다.

검증에 사용한 일회용 DB는 종료 후 제거를 확인했으며 기존 서비스 DB는 실행 중이다. 이번 공개 변경물 15개는 모두 10MiB 미만이다. 기존 원상담 106,583개 검사 단위와 대조한 80자 이상 완전 일치는 0이었다. 이 검사는 짧거나 변형한 발췌·이미지 속 문자·과거 이력·원격 공개까지 없다고 보증하지 않는다. 결과는 `operations/cleanup.json`, `owned-content-check.json`에 보관했다.
