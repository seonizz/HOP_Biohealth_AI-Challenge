# 대회 준비 문서

대회 요구와 발표 준비에 필요한 내용만 이곳에서 관리합니다. 현재 앱·검사·남은 작업은 [공통 현황](../current/현황과_할일.md), 데이터와 모델 수치는 [데이터와 연구](../current/데이터와_연구.md)를 참조합니다.

- [대회 요구와 적합성](01_대회요구와_적합성.md): 과제 범위와 운영계획(안)에 기재된 제출 조건.
- [발표 주장·슬라이드별 검토](03_발표주장과_PPT검토.md): 기존 덱에 남은 수정사항.
- [발표자료 위치](../../presentation/README.md): 수치·수집 도구·슬라이드.

기존 핵심 요약·구성·우선순위 문서는 중복 본문을 제거하고 공통 기준 문서로 연결했습니다. 과거 archive 원문 일부는 현재 체크아웃에 없어 현재 코드와 저장된 근거로 대조합니다.

- [적대적 평가 v1](결선_적대적_평가_v1.md): 최초 관측을 보존한 기준.
- [대응·재검증 v2](결선_적대적_평가_v2.md): 수정, 실제 검사, 남은 외부 증거.
- [적대적 재평가 v2](결선_적대적_재평가_v2.md): 추가 검증 후 처리시간 제외 재채점 48/90 (v2.1), 새 경계 결함과 남은 검증 조건.
- [제출 범위와 검증 계약](04_제출범위와_검증계약.md): 과제 대응·독립 평가·현장 사용·운영의 사전 조건.

- [재평가 N1–N4 수정 v3](결선_재평가_지적_수정_v3.md): 안전 인용·요청 계측·실행 환경 구분·웹 실패 이력 보존과 새 검증 결과.

- [강화 적대적 재평가 v3](결선_적대적_재평가_v3.md): N1–N4 종결 확인, 처리시간 제외 58/90, 실제 장문 출력 실패·후속 정정 경계와 독립 검증 근거.

- [재평가 v3 대응 수정 v4](결선_재평가_지적_수정_v4.md): 안전 근거 ID 선택·후속 출처 보존·불완전 로그 검사와 실제 생성 재검증.

- [학습 데이터 기준 재평가 v4](결선_적대적_재평가_v4.md): 모델 자체·처리시간 제외 68/90, 학습 데이터 직접 검증 14/20, 빈 전송 상태 결함과 검증 범위.

- [재평가 v4 A1 대응 수정 v5](결선_재평가_지적_수정_v5.md): 빈 서술형 전송을 건너뜀으로 통일하고 HTTP·저장·재조회·근거 제외를 검증. 재채점은 수행하지 않음.

- [엄격 적대적 재평가 v5](결선_적대적_재평가_v5.md): 모델·처리시간 제외 68/90, 데이터 13/20. 원 A1 종결, 학습 목표의 긴 부분 노출 9행과 보이지 않는 입력의 P3 경계를 독립 재현.
