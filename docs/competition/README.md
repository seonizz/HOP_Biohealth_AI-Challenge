**2026-10-18 인계 도구 후속 수정:** [v13 HR5·HR6 수정과 인계 재검증](결선_v13_HR5_HR6_수정과_인계재검증_2026-10-18.md). 입력 해시·실제 소비 바이트의 결속과 Unicode JSONL 왕복을 수정했고 인계 검사 37개 및 실제 28단위의 새 버전을 검증했다. 이전 인계본은 보존했으며 사람 승인·독립 test·점수 상향을 뜻하지 않는다. 아래 2026-10-16 점수·수량은 당시 검증 범위의 기록이다.

**최신 가중 집중도 재검증 v11:** [대안 비교·정책 적용·실제 토큰 재검증](학습데이터_가중집중도_개선_재검증_v11.md). 2026-10-17, 사용자 선택에 따라 **419행 전부**를 보존하고 양수 가중 정책을 적용했다. train은 입력·정답 균형 성분을 절반씩 섞고 validation은 보조 가중 집계로 사용한다. **정규화 HHI 1항목·CV 5항목 악화는 가중 지표에서 해소**됐으며, 원행 지표와 무가중 primary validation은 그대로 공개한다. **정답 17,220토큰과 과업×split별 총량**, 원문·전체 맥락·기존 대표·분할을 보존했다. 실제 tokenizer에서 출력 **8,192** 및 실제 시퀀스 **4,096 이하** 조건 419/419, 관련 회귀 **125개**를 통과했다. 실제 입력 **157,668토큰**은 그대로이고 가중 입력 질량 **155,184.651**은 토큰 절감량이 아니다. 신규 사례의 상대 영향량 감소와 작은 합성 집합·사람 검토·독립 test·앱 전체 정답 부족도 기록했다. 별도 가중 손실 소비 경로를 추가했으며 모델 학습·점수 상향은 수행하지 않았다.

**보존한 실제 토큰 재검증 v10:** [토크나이저 복구·실측·집중도·적대적 검증](학습데이터_실제토큰_집중도_재검증_v10.md). 기존 서버와 SHA-256이 같은 고정 토크나이저를 로컬에 복구해 **419파생행 전부**를 새로 인코딩했다. 출력 **8,192** 예약과 실제 시퀀스 **4,096 이하** 조건 모두 통과했으며 최장 시퀀스는 **3,909토큰**이다. 전체 입력 **157,668**·정답 **17,220토큰**, 그중 신규 279행은 입력 **129,065**·정답 **12,014토큰**이다. 원문·맥락·split과 원상담 v8은 보존했다. raw HHI 18개 비교는 모두 감소했지만 정규화 HHI 1개·CV 5개 악화는 남는다. 과업별 파생 행의 재고 합계이며 자동 혼합·사람 승인·독립 test나 학습 완료를 뜻하지 않는다.

**보존한 주변인 과업 구성 v9:** [대안 비교·적용·적대적 재검증](학습데이터_주변인지원_과업정합성_개선_재검증_v9.md). 원상담 v8과 기존 주변인 20대화는 그대로 보존하고, 신규 합성 24대화·48응답을 추가해 주변인 후보를 **44대화·72응답**으로 구성했다. validation 다중턴은 **0→12대화**, 동료 관계는 **0→4대화**다. 현재 앱의 원문 관찰·reported 관계 기억 단계도 합성 12맥락에서 **24정답쌍**을 별도로 만들었다. 신규 정답은 다른 AI 검토자가 교정 후 확인했으며 사람·전문가 승인이나 독립 test가 아니다. v9 작성 당시 출력 **8,192**·유효 입력 **61,440** 계약만 적용하고 실제 토큰 길이는 미검증으로 남겼다. 해당 공백은 후속 v10의 동일 tokenizer 실측으로 해소했으며 v9 원본·manifest는 당시 상태로 보존한다. 기존 원상담의 토큰 집중도·총량·맥락·분할은 그대로이고 전체 앱 단계의 목적 정답·실제 주변인 검토는 남는다.

보존한 원상담 구성은 [입력 총량·절차성 문맥 개선·재검증 v8](학습데이터_입력총량과_절차문맥_개선_재검증_v8.md)입니다. 출력 **8,192**·합산 **69,632**·유효 입력 **61,440**에서 짧은 후보 **1,052행·1,036상담·후기 50셀**, 긴 후보 **2,376행·1,038상담·후기 1,293셀**을 유지했다. 동일 정답 길이의 전기 원행 **5·4개** 교체로 입력 집중도 **18지표 모두 v7보다 개선**됐고, 입력은 **2,094,059→2,089,385 / 14,190,420→14,183,561토큰**, 절차성 플래그는 **389→387 / 1,199→1,198**로 줄었다. 정답 총량 **75,231·213,050토큰**, 정답 집중도·셀별 길이·그룹별 합·행 집중도는 그대로다. 짧은 split은 v5 입력·플래그 상한, 긴 split은 v6 상한을 충족하고 v6 대비 신규 플래그 셀은 0이다. 긴 validation 입력은 v5보다 **1,456토큰 많고**, 짧은 후보에는 v5 대비 신규 플래그 셀 **1개**가 남는다. 원문·새 정답까지의 전체 맥락·보류·split·후기 ID와 후기 패널 105행의 압축 바이트는 보존했다. 전기 정답의 의미적 동등성·사람 검토·목적 적합성·독립 test는 미검증이며, 짧은 validation 후기 2셀·마지막 ¼ 0행의 부족은 남는다. 관련 **16모듈 329개(신규 v8 26개 포함)** 재실행은 위 v11 당시 검사와 합산하지 않습니다.
