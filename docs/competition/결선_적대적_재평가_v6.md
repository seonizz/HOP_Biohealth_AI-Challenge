따라서 **분할 3→4/5**는 전체 source admission의 부분 노출 통제와 실제 산출물 일치가 재현됐다는 판단이다. 기존 4,096 후보의 내용 개선·모델 성능 향상에는 점수를 주지 않았다. 의미 중복·인물 독립성·미사용 최종 평가셋의 제한 때문에 5점으로 올리지 않았다.
