# 재평가 v4 A1 대응 수정 v5

기준일: 2026-10-15. 기준 커밋 `b73dd02`. [재평가 v4](결선_적대적_재평가_v4.md)의 새 P2 결함 A1, 빈 서술형 전송이 실제 답변·근거로 등록되는 경로를 수정했다. 이 문서는 수정·검증 기록이며 새 점수를 부여하지 않는다. 기존 68/90점과 학습 데이터 14/20점은 당시 평가 기록으로 보존한다.

## 수정한 동작

빈 Send가 건너뛰기 표시 문자열만 전달하고 `skipped`를 생략하던 것이 원인이었다. UI가 빈 입력·공백·정확한 표시 문자열을 명시적 건너뜀으로 전달하도록 고쳤다. Enter 전송도 같은 핸들러를 사용한다. 서버도 동일하게 정규화하므로 이전 클라이언트가 플래그 없이 전송해도 실제 답변이 되지 않는다.

| 입력 | 처리 |
|---|---|
| 선택적 서술형의 빈 문자열·공백·정확한 `(건너뛰었어요)` | `skipped`, 답변 수 불증가, 검색·안전 근거 후보에서 제외 |
| 필수 또는 `noSkip` 서술형의 위 입력·명시적 건너뜀 | UI에서 전송 차단, 직접 API 요청은 기존 `400 answer_required`, 저장 상태 불변 |
| “네” 선택 후 선택적인 부가 설명만 비움 | 선택한 “네”는 실제 답변으로 보존 |
| 실제 입력한 “모름”·“없음”·부정문·괄호 포함 문장 | 원문과 실제 답변 상태 보존 |

기본·후속 답변 구분과 원문 보존 계약을 유지한다. 이미 저장된 과거 기록을 일괄 변환하는 마이그레이션은 포함하지 않는다. 새 전송과 이전 질문으로 돌아가 다시 답하는 경로에 적용한다.

## 같은 반례의 재검증

v4의 프로브를 별도 로컬 경로에 복사해 **동일 스크립트**로 다시 실행했다. 새 일회용 PostgreSQL에 마이그레이션을 적용한 기본 29문항에서 동일한 8단계 경로로 `describe`에 도달했다.

| 동작 | 수정 전 상태 / 답변 수 / 검색 문서 / 안전 후보 | 수정 후 상태 / 답변 수 / 검색 문서 / 안전 후보 |
|---|---|---|
| 빈 Send | answered / 7 / 1 / 1 | **skipped / 6 / 0 / 0** |
| 명시적 Skip | skipped / 6 / 0 / 0 | **skipped / 6 / 0 / 0** |

이 표의 프로브는 실제 UI 핸들러를 mock DOM에서 실행한 상태·근거 비교다. HTTP와 저장은 아래 별도 API 회귀검사에서 확인했다. 실제 브라우저 전체 E2E로 표현하지 않는다.

## 새 회귀검사와 실행 결과

총 13개 회귀검사를 추가했다.

- UI 7개: 빈 Send·공백·표시 문자열·Enter·명시적 Skip의 실제 대화 요청 payload, 필수/noSkip/후속 문항의 차단, “네” 이후 빈 설명의 선택 보존.
- 상태 3개: 대기 상태와 완료 상태의 건너뜀 유지, 필수 후속 답변 거절, 불확실·부정·괄호 포함 실제 문장 보존.
- API 3개: HTTP→암호화 저장→재조회→최종 기록의 상태와 근거 제외, 되돌리기 후 실제 답변·근거 복구, 필수/noSkip 거절 시 revision·로그·상태 이력·gateway 호출 불변.

| 실행 | 결과 | 범위 |
|---|---|---|
| `TEST_DATABASE_URL=<일회용 DB> npm test` | **281 통과, 실패·제외 0** | 실제 HTTP·PostgreSQL, gateway는 mock |
| `npm run test:evidence` | **24 통과, 실패·제외 0** | 평가 근거 도구 회귀 |
| `npm run check` | 통과 | JavaScript 구문·JSON 파싱 |
| 동일 빈 전송 프로브 | 두 경로 동등 | 답변 수 6, 해당 검색·안전 후보 0 |

근거 경로·해시는 [검증 근거 JSON](결선_재평가_지적_수정_v5_근거.json)에 기록했다. 원시 로그와 프로브는 Git 제외 경로 `runtime/adversarial-fixes-v5/`에 보존한다. 일회용 DB만 사용했으며 검사 후 종료했다.

## 범위와 남은 과제

[사용자 지정 UI 원칙](../../app/docs/UI_CONTENT_POLICY.md)에 따라 서비스에는 개발·평가 상세를 추가하지 않고 이 문서와 [API 계약](../../app/docs/API.md)에 남겼다. 이 정보 범위는 사용자가 직접 지정했다.

모델 자체와 처리시간은 [새 평가 기준](05_평가범위와_학습데이터_기준.md)에 따라 제외했다. 실제 모델 실행·학습·데이터 재감사를 수행하지 않았다. v4에서 확인한 데이터 해시·특징·원문·누출 검사 결과를 이번 실행으로 합산하지 않는다.

주변인 지원 목적에 맞는 입력–정답 구성, 의미 라벨 검토 범위, 독립성·대표성, 접근 상실·보유·삭제의 실제 운영 근거는 계속 남아 있다. 이번 A1 수정만으로 그 항목이 해결됐다고 표시하지 않는다. 이전 평가서·근거 JSON·학습 데이터·발표 기준본은 보존했다.
