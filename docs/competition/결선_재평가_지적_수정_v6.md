# v5 지적 사항의 적대적 재검토

검토일: 2026-10-15. 대상은 [엄격 재평가 v5](결선_적대적_재평가_v5.md)의 A2 입력 결함과 D1 부분 노출이다. 아래 결과는 검증 당시 소스·데이터 후보에 한정한다. [사용자 지정 기준](05_평가범위와_학습데이터_기준.md)에 따라 모델 자체와 처리시간은 제외했으며, 기존 68/90점·데이터 13/20점은 재채점하지 않았다.

## 검토 결과

| 항목 | 판정 | 확인한 근거 |
|---|---|---|
| A2 — 보이지 않는 문자로 필수 답변 통과 | 검사 범위에서 재현되지 않음 | 필수·`noSkip`·필수 후속 답변의 내용 없는 입력 거절. 선택형 직접 입력도 같은 경계 검사 통과 |
| 내용 없는 입력의 답변·근거 등록 | 검사 범위에서 차단 확인 | 선택적 빈 서술형은 건너뜀으로 처리. 내용 없는 부가 설명은 검색·안전·상태 근거에서 제외 |
| 정상 Unicode 입력 손상 | 검사 범위에서 발견되지 않음 | ZWJ 가족 이모지, 결합 악센트, 한글 자모와 내용 있는 입력 원문 보존 |
| D1 — 정답의 200자 이상 부분 노출 | 기존 후보 9행 재현, 추가 보류 후보 0행 | 운영 코드를 import하지 않은 독립 검색에서 동일 결과. 독립 검출·정책·장부의 변경 ID가 같은 9개 |
| 보류 전파·원본 보존 | 대조 통과 | 원본 45,974행 식별자와 기존 보류 결정 대조. 감시한 입력·출력 20파일의 검사 전후 해시 동일 |

부분 노출 검색은 정규화한 validation 정답과 허용된 train의 과거·최종 assistant 메시지 사이의 연속 문자 일치를 대상으로 했다.

| 검사 대상 | Train | Validation | 합계 |
|---|---:|---:|---:|
| 기존 내용 보류 후보 | 40,415 | 4,298 | 44,713 |
| 부분 노출 9행 추가 보류 후보 | 40,415 | 4,289 | 44,704 |
| 새 정책과 기존 4,096 길이 조건을 적용한 후보 | 15,512 | 1,724 | 17,236 |

9행 모두 기존 길이 조건에서도 보류 대상이었다. 최종 export에는 해당 9행이 없으며, 압축 해제한 원문 바이트는 기존 4,096 후보와 동일했다.

## 검증 근거

- 앱 **294개**, 평가 도구 **24개** 통과. 같은 작업 디렉터리의 병행 재평가 로그를 확인하고 당시 146파일의 해시를 대조했다.
- 데이터 **337개 통과·8개 제외·실패 0**. 제외된 8건은 기존 torch 의존 검사다. 집중 검사 72개는 전체 345개에 포함된다.
- 앱 검사는 실제 HTTP·일회용 PostgreSQL과 mock 모델을 사용했다. UI는 실제 핸들러를 mock DOM에서 검사한 범위다.
- 세부 해시와 독립 검사 결과는 [검증 근거 JSON](결선_재평가_지적_수정_v6_근거.json)에 있다.

## 남은 한계

- **9행 모두 의미 검토 대기**다. 반복 양식과 실질 정답 노출의 구분은 확정되지 않았고 사람 검토는 0건이다.
- 200자 미만, 의미상 유사성, 불연속 중복, train의 사용자 메시지와의 노출은 이번 검사로 배제할 수 없다.
- 동일 인물의 분할 실패는 확인되지 않았다. 문자 일치만으로 인물 독립성을 입증할 수도 없다.
- validation을 선별에 사용했으므로 미사용 최종 test로 간주할 수 없다.
- 주변인 지원 정답 구성과 의미 라벨 검토 범위는 여전히 부족하다.
- 합성 U+0000 포함 입력은 검색 오류로 중단된다. 실제 검사 대상에는 0건이었으며 잘못 허용되는 동작은 관찰되지 않았다.
- 이번 검증은 신규 브라우저 전체 E2E를 포함하지 않는다. 이후 변경된 소스까지 통과했다고 확대 해석할 수 없다.
