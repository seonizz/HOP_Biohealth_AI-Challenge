# 제출 범위와 검증 계약

2026-10-15 기준. 이 문서는 현재 구현의 설명 범위와 **앞으로 새로 수집할 평가**의 내부 통과 조건을 고정한다. 주최 측 승인, 임상 기준, 완료된 사람 평가를 대신하지 않는다. 기존 개발 사례를 독립 test로 다시 이름 붙이지 않는다.

## 목표에서 사용자 출력까지

| 구분 | 입력과 목적 | 실제 실행·출력 | 인정하는 증거 | 아직 연결하지 않은 주장 |
|---|---|---|---|---|
| 대회 분류 연구 | 상담 대화, 원자료 코호트 4범주 | TF-IDF + Naive Bayes의 별도 분류 실험 | validation 117행·관측 그룹 23개, Macro F1 0.5535 | 앱의 질환 판별, 독립 인물 일반화, 임상 진단 |
| 목표 31B 학습 | 원본 상담 맥락에서 다음 상담사 응답 예측 | Gemma 4 31B step100, 800행 부분학습 | 고정 32행·정답 2,905토큰 NLL 4.685542 → 2.922296 | 주변인 가이드 품질·안전 향상, 전체 데이터 학습 완료 |
| 현재 지원 앱 | 주변인이 직접 입력한 현재 대화 | 임시 12B, 관찰 정리·첫마디·행동·자기돌봄 | 앱 계약 검사와 별도의 합성 개발 사례 | 31B 서비스 완성, 사람 검수 완료, 치료 효과 |

앱은 분류 기준 모델을 호출하지 않고 증상 점수를 생성하지 않는다. 현재 대화 원문 검색은 외부 임상 지식 검색이 아니다. 과제 간 가치 전이는 별도의 연구 가설이며, 승인된 최초 계획서·멘토 피드백이 확보되기 전에는 범위 승인을 주장하지 않는다.

## 실행 조합을 식별하는 방법

- `/health`의 `source_sha256`, `prompt_version`, `model_requested`를 시연 직전에 확인한다. SHA256은 앱 `src`, 질문 seed, 공개 JS/JSON/HTML/CSS, migrations, package·lock 파일을 포함한다. 프로세스 기동 시 계산하므로 코드 변경 후 재시작한다.
- 새 결과의 `provenance.source_sha256`과 `/health`를 대조한다. 저장·재조회한 기록도 같은 값이어야 한다. 기존 기록은 소급해서 새 실행 결과로 바꾸지 않는다.
- 합성 평가 도구는 동일 규칙의 소스·질문·사례 해시, 프롬프트, 요청 모델, timeout, 실패 및 재시도를 저장한다. 모델 alias는 체크포인트 로딩의 증명이 아니다. `runtime_model_identity_verified:false`를 유지한다.
- 최종 31B의 adapter·기반 모델 digest는 서버의 로딩 기록으로 대조해야 한다. `MODEL_CHECKPOINT_SHA256`은 선언값만 기록하며 검증 완료로 취급하지 않는다. 현재 step100을 최종 제출 체크포인트로 임의 확정하지 않는다.

재현 명령과 출력 위치는 [AI 평가 도구](../../ai/local_api/RELATIONSHIP_AGENT.md)를 따른다.

## 신규 독립 평가의 사전 조건

| 평가 | 고정할 설계 | 내부 통과 조건 | 결과 기록 |
|---|---|---|---|
| 상담 분류 | 기존 train·validation·프롬프트 개발·정성 검토에 노출되지 않은 원천 그룹을 확보. 실제 인물 확인 범위를 기록. 같은 상담·중복 원문은 전부 같은 분할. 라벨 검토 후 test 해시 동결 | test 각 클래스 20상담 이상·30원천 그룹 이상 확보를 착수 조건으로 사용. 동일 test의 기준 모델 대비 Macro F1 차이 ≥0.05, 그룹 단위 bootstrap 95% 구간의 하한 >0 | 클래스별 precision/recall/F1, 혼동행렬, 그룹 수, 제외·실패 분모, 2,000회 그룹 bootstrap seed 기록 |
| 주변인 지원 | 개발에 쓰지 않은 30개 시나리오. 초기·누적·정정·위험 부정·현재 위험·사람 혼동 각 5개. 동일 기반 31B의 학습 전후를 같은 프롬프트·예산·환경에서 생성 | 두 독립 검토자가 원문 충실성·사람/시점/부정 보존에서 각각 90% 이상 적합 판정. 중대한 근거 조작·사람 혼동·위험 반전은 0건이어야 다음 단계 진행 | 실패 생성도 분모 포함. 원문과 무편집 출력, 두 독립 점수, 불일치·최종 합의 기록. 유용성은 별도 1~5점 분포와 쌍별 차이 |
| 구성요소 기여 | 동일 모델·동일 30개 사례에서 단순 프롬프트, 검색 제외, STATE 제외, 검토 제외, 전체 구성 비교. 순서 무작위화 | 원문 충실성·유용성 차이의 구간을 함께 보고. 개선이 확인되지 않으면 독창성 효과를 주장하지 않음 | ablation 이름·모델·프롬프트 해시·토큰 예산·실패·비용을 별도 열로 유지 |
| 전체 웹 흐름 | 위 시나리오 중 6개 유형을 포함해 순차 10세션, 동시 2사용자 조건을 따로 수행. 모델·하드웨어·소스 고정 | 저장·재조회·정정·소유자 격리 오류 0. 모델 처리 p95와 실패율을 공개하고 UI 기대시간을 실측에 맞춤 | 입력 시간, 모델 대기, 최종 생성, 전체 세션 시간을 각각 기록. 네트워크 실패·재시도 포함 |

이 숫자는 이번에 정한 **개발용 수용 기준**이며 임상 안전성의 기준이 아니다. 표본 확보 전에 변경할 수 있으나 결과를 본 뒤에는 기준 버전을 바꾸고 별도 새 평가를 해야 한다. 개발 사례 4종과 기존 validation을 이 test에 포함하지 않는다. 노출 이력이 불명확하면 독립성 상태는 `unverified`로 남긴다.

사람 평가 행의 필수 항목: `case_id`, `source_group_id`, `output_hash`, `blind_label`, `reviewer_id`, `reviewed_at`, `faithfulness_pass`, `subject_time_negation_pass`, `critical_error`, `usefulness_1_to_5`, `reason`, `adjudication`. 작성하지 않은 값은 미평가이며 0점이나 통과로 채우지 않는다. 모델 검토 점수는 사람 평가 열에 넣지 않는다. 학습·평가 원문과 사람 식별자는 Git에서 제외한 `training_data/` 또는 `runtime/`에 보관한다.

## 한 가지 현장 사용 가설과 운영 확인

검증할 첫 사용 상황은 **성인 가족·친구가 비긴급 상황에서 대화를 준비하는 사전 정리**다. 이용자는 주변인, 검토를 요청할 대상은 상담기관 실무자, 도입·비용 부담자는 해당 기관이라는 가설이다. 기관 도입·지불 의향은 아직 확인되지 않았다.

최초 사용성 확인은 동의한 성인 5명이 합성 상황으로 진행한다. 과업은 답변 입력, 첫마디 이해·수정, 모르는 내용을 구별하기, 완료 기록 삭제다. 완료 여부·걸린 시간·부담(1~5)·도움(1~5)·재사용 의향·부정적 의견을 그대로 기록한다. 진행자는 해석을 유도하지 않는다. 기록은 사용성 관찰이며 임상 효과나 시장 수요 추정으로 확대하지 않는다.

현재 보관 계약: 답변·대화·상태 이력·결과를 암호화 저장하고 연결 모델에 전송한다. 기본 30일은 접근 세션 수명이며 자동 보유기간이 아니다. 접근 가능한 완료 기록은 연결된 대화·상태 이력과 함께 삭제된다. 미완료 대화 삭제 UI, 쿠키 소실 후 복구·삭제, 자동 보유기간은 아직 구현·확정되지 않았다. 서비스에는 저장·삭제에 필요한 안내만 간결하게 표시한다. 모델·평가·개발 상세는 사용자 지정 [UI 정보 원칙](../../app/docs/UI_CONTENT_POLICY.md)에 따라 문서에 보관한다. 기존 데이터의 일괄 삭제는 수행하지 않았다.

외부 이용 전 운영 담당자·연락 경로·보유기간·백업 삭제 범위·쿠키 소실 후 처리 절차를 확정하고 실제 삭제를 확인해야 한다. 비용은 `GPU 시간 × 확인한 시간당 비용 + 호스팅 + 저장 + 운영 인력`으로 산정하되 미확인 단가는 0원으로 넣지 않는다. 현재 합성 평가의 토큰·대기는 비용 측정의 입력이며 최종 세션 원가가 아니다.

## 발표와 Q&A

발표 기준본은 [발표자료 안내](../../presentation/README.md)에서 한 개로 지정한다. 운영계획(안)에 기재된 발표 15분·Q&A 5분에 맞춰 구성하되 최신 공지 확인·제출·리허설 완료는 별도 상태다. 큰 숫자의 본문에 모델·표본·지표를 남기며, 37.63%는 NLL 상대 감소로만 사용한다. 미확인 시장 수치와 원출처 미대조 연구 일치율은 기준본에서 제외한다.
