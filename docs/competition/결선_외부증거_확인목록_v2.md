## 바로 사용할 준비물

1. [사람 검토 인계 절차](../../data/docs/support_agent/사람검토_인계_절차_v1.md)의 **`human_review_v10_20261016_r3`**를 사용한다. manifest SHA-256은 **`a4f5b0aac96e870cdc88480e6352d601b39ef7d975478db9219bb6a5f0554135`**다. 검토 내용은 `_r2`와 같고 HR2 수정 코드의 해시로 새 버전을 검증했다. 28단위는 모두 대기, 학습·운영·독립 test 승인은 false다.
2. 먼저 `blind_inputs.jsonl`에 대응하는 독립 판단을 별도 기록하고, 이후 `target_packets.jsonl`의 응답·근거와 대조한다. [검토 계약](../../data/docs/support_agent/결선_데이터_검토계약_2026-10-16.md)의 항목을 사용한다. 초기 pending 묶음을 승인 완료로 덮어쓰거나 AI 판정의 검토자 이름만 바꾸지 않는다.
3. 인계는 현재 **같은 해석된 절대 입력 경로·바이트·구현**을 요구한다. 다른 작업 루트로 옮길 때는 새 버전·manifest와 단위 내용 해시를 대조한다. 경로 제약을 문서화했지만 이식성 기능은 아직 없다. 원문 접근 권한이나 사람 판정의 진위를 해시만으로 인증하지 않는다.
4. [대안 비교·현장 검증 계획](결선_대안비교와_현장검증_v1.md)의 사전 과업과 기록표로 실제 관측을 남긴다. 비교 순서를 교차 배정하고 도움·실패·중단을 분모에서 제외하지 않는다. 짧은 시연의 선호를 임상 효과나 전체 시장의 우월성으로 확대하지 않는다.
5. [운영 증거 계약](../../app/docs/DATA_RETENTION.md)에 실제 승인·설정·저장 위치·복원 기록을 연결한다. 지원 형식은 UTF-8 JSON/JSONL/NDJSON/TXT/MD다. 형식·해시·명시적 모순 검사가 통과해도 승인자의 신원·사실·물리 삭제가 인증된 것은 아니다. PDF·이미지 원본은 보존하고, 지원 형식의 동반 기록과 원본 대조 결과를 남긴다.

최신 [데이터 v5](학습데이터_4096_대안비교와_집중도완화_재검증_v5.md)는 행 기준 집중도를 완화한 구성이다. 새 사람·새 원천·사람 승인 정답·독립 test를 확보한 것은 아니다. 짧은 후기 공백과 토큰 기준 일부 집중도 잔여를 기록하고, 여러 후보·105행 패널의 겹치는 사례를 합산하지 않는다.

## 증거의 기록과 보관

각 실제 기록에 `항목 ID / 현재 상태 / 대상 버전·내용 SHA-256 / 수행일·시간대 / 확인된 수행자와 역할 / 관측·판정·사유 / 근거 파일·SHA-256 / 남은 조건`을 남긴다. **준비 → 실제 수행 → 검토 → 승인 → 운영 적용**을 구분한다. 결과가 없으면 대기, 불일치나 반려가 있으면 보류·수정 필요로 유지한다. 수정된 내용에는 이전 판정을 자동 재사용하지 않는다.

상담 원문·학습 행·실제 신원·개별 검토 내용은 접근을 통제한 Git 제외 경로에 보관한다. 공개 보고서에는 원문 없는 집계·버전·방법·한계만 남긴다. 이번 작업은 사람이나 기관에 연락하거나 실제 검토·회신을 만들어 내지 않았다.

최종 공지·일정은 이번 수정 작업에서 새로 조회하지 않았다. 제공 운영계획(안)의 준비 기준과 v1에 기록된 과거 공지 확인을 보존하되, 최종 통보·제출 조건 확인으로 승격하지 않는다. 첨부 문서 내용은 참고 근거이며 사용자의 실행 요청과 구분한다.
