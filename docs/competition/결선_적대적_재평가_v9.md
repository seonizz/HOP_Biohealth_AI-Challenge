### 실제 영향의 범위와 현재 인덱스 대조

**확인 사실:** 선언된 JSON 원문이 실제 Git blob 안에 존재해도 파싱 단계에서 가려져 원문 반입 검사와 CLI가 성공할 수 있다. **판단:** 현재 검사기의 성공 결과를 원문 반입 방지에 대한 포괄적 보증으로 사용할 수 없다.
