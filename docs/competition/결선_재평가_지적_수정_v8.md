# 결선 v8 G2 인코딩 경계 수정

2026-10-16 · `531522f` 위의 현재 작업 트리. [v8 평가서](결선_적대적_재평가_v8.md)의 **75/90점**과 재현 기록은 보존한다. 이 문서는 G2 수정·검증 기록이며 재채점이 아니다.

## 수정

[Git 검사기](../../tools/audit_git_privacy.py)가 `.json`, `.jsonl`, `.ndjson`을 일반 바이너리 건너뛰기보다 먼저 처리하도록 변경했다. **UTF-8과 선택적 UTF-8 BOM을 지원**하며 다른 인코딩이나 해석 불가능한 내용은 오류로 처리한다. UTF-16을 원문 없는 파일로 간주하거나 자동 변환하지 않는다. 같은 정책은 gzip 해제 후 JSON과 Office 내 JSON 첨부에도 적용된다. 오류 출력에는 원문이나 파서 메시지를 넣지 않는다.

v8 반례를 먼저 [회귀검사](../../tools/test_audit_git_privacy.py)에 추가해 기존 코드에서 `passed:true` 때문에 실패하는 것을 확인했다. 수정 후에는 같은 인덱스 blob을 검사한 결과 `passed:false`, 해석 오류 1건으로 차단한다. 작업 파일을 빈 JSON으로 바꿔도 스테이징된 UTF-16 내용에 대한 차단이 유지된다.

| 동일 합성 반례 | 수정 전 | 수정 후 |
|---|---|---|
| UTF-8 JSON의 원문 일치 | 1파일, 정상 차단 | 1파일, 정상 차단 |
| 같은 값을 가진 UTF-16 JSON | `binary_not_scanned:1`, 잘못된 통과 | 오류 1건, 차단 |
| UTF-16 결과의 `passed` | `true` | `false` |
| 원문·학습 데이터 출력 또는 수정 | 없음 | 없음 |

재현 명령은 다음과 같다. 테스트는 새로 만든 합성 원문과 임시 Git 저장소를 사용한다. 전체 인덱스 감사는 로컬 원천을 해시로 대조하고 내용을 출력하지 않는다.

```sh
python3 -B -m unittest discover -s tools -p test_audit_git_privacy.py -v
python3 -B tools/audit_git_privacy.py --scope tracked --output runtime/remediation-v8/privacy-tracked.json
python3 -B tools/audit_git_privacy.py --scope staged --output runtime/remediation-v8/privacy-staged.json
python3 -B runtime/remediation-v8/independent_attacks.py
```

[근거 JSON](결선_재평가_지적_수정_v8_근거.json)은 실패 재현·새 검사 로그·독립 재실행·전체 인덱스·보존 확인의 파일 해시와 연결된다. v8 독립 스크립트는 경로만 새 작업 폴더로 옮겨 실행했으며 원래 평가 산출물을 덮어쓰지 않았다.

## 보존과 남은 범위

이번 수정은 검사기·검사·설명 문서에 한정한다. Git 인덱스와 스테이징 내용, HEAD, 기존 평가서는 전후 해시를 확인했다. 기존 추적 해제 대상 1,223파일은 그대로 로컬에 보존돼 있다. 제품 코드·학습 데이터·발표 자료를 수정하거나 커밋·푸시하지 않았다.

앱 소스 fingerprint는 `958d818e514f187794e6d04e7221f5c0792c9eed1d6f8ee5fbf0f055ad458e62`로 같다. 앱 391개·데이터 225개·평가 도구 24개는 **사용자가 제공한 v8의 기존 실행 근거**이며 이번 인코딩 수정에서 새로 실행한 검사로 표시하지 않는다.

G2의 잘못된 통과는 수정했지만, 일반 바이너리·이미지 문자·짧거나 변형된 발췌·과거 커밋·원격 공개 여부까지 해결한 것은 아니다. 전체 지원 범위와 제한은 [검사기 안내](../../tools/README.md)에 명시했다.

사람이 승인한 주변인 과업 정답, 데이터의 후반부 대표성 개선과 자료 사용 범위 확인, 실제 이용자 관찰·기관 도입, 운영 책임·백업 삭제, 제출 조건·리허설은 기존 미완료 상태다. 대기열 391개와 작성 요청 6개를 완료된 사람 검토로 바꾸거나 외부 승인을 만들어 넣지 않았다.
