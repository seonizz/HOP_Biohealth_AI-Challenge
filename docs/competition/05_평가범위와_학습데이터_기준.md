# 향후 평가 범위와 학습 데이터 기준

기준 버전: v1 / 2026-10-15. 사용자가 지정한 향후 프로젝트 평가 기준이다. 기존 처리시간 제외 요청을 유지하고, 기존 모델 관련 배점의 평가 대상을 **모델을 학습할 데이터**로 변경한다. 이 문서 자체는 새 프로젝트 평가나 재채점 결과가 아니다.

## 적용 범위

| 구분 | 앞으로의 처리 |
|---|---|
| 모델 자체 | 모델 크기·종류, 학습 진행률·완료 여부, NLL·F1 등 모델 성능, 생성 품질, 실제 모델 실행 통과율, 체크포인트 로딩·최종 모델의 앱 통합 여부를 채점에서 제외 |
| 학습 데이터 | 목적 적합성, 원천·가공 품질, 라벨·학습 목표, 분할·누출 방지, 이력·재현 근거를 평가 |
| 시간 | 처리시간·속도·대기시간과 이에 따른 시연 감점 제외 |
| 앱 자체 | 입력·정정·근거 및 출처 보존, 검증 계약, 저장·재조회·삭제·소유자 격리, 실패 이력 등 모델과 구분 가능한 구현을 평가 |
| 현장 발표 | 관찰한 범위만 평가. 실제 발표·Q&A를 관찰하지 않았으면 해당 점수 유보 |

최종 31B 미통합이나 독립 모델 성능 평가 부재를 완성도·적용가능성·발표 항목에 옮겨 감점하지 않는다. 모델 출력의 의미 판단만으로 앱 코드 결함을 확정하지 않는다. 앱 결함은 모델과 구분 가능한 코드·계약·재현 결과로 판단한다.

모델 관련 사실과 과거 실험 기록은 연구 이력으로 보존할 수 있지만 채점 근거로 사용하지 않는다. 동일하게, 모델 성능이 좋다는 이유로 학습 데이터 품질을 입증했다고 보지 않는다.

## 향후 내부 배점

| 항목 | 배점 | 평가 대상 |
|---|---:|---|
| 창의성·차별성·완성도 | 30 | 문제와 사용자 정의, 서비스 구성의 차별성, 모델 제외 범위의 구현 완성도 |
| **학습 데이터 — 기존 모델 관련 항목 대체** | **20** | 아래 네 항목 각 5점 |
| 적용가능성 | 30 | 모델·시간을 제외한 사용 흐름, 운영 기능, 실제 활용·확장 근거 |
| 발표력 | 20 | 자료와 주장 정합성, 관찰한 전달·태도·Q&A |

공식 운영계획의 30·20·30·20 배점 틀을 참고하되, **모델 항목을 데이터로 대체한 것은 사용자 지정 내부 평가 방식**이다. 주최 측 평가표가 변경됐다고 표현하지 않는다. 기존처럼 발표 자료 10점과 현장 10점을 내부적으로 구분할 경우, 현장 미관찰 상태의 확인 범위는 90점이다.

## 학습 데이터 20점의 근거

| 세부 항목 | 배점 | 확인할 내용 |
|---|---:|---|
| 목적 적합성과 구성 | 5 | 실제 학습 목표와 입력·정답의 연결, 당사자 상담 데이터와 주변인 지원 과업의 차이, 활용 가능한 사례·대상·상황의 범위와 편중 |
| 원문·가공·라벨 품질 | 5 | 누락·손상·중복 처리, 화자·순서·정정 맥락 보존, 라벨 또는 응답 정답의 정의, 선별·제외 근거와 표본 검토 |
| 분할과 누출 방지 | 5 | 상담·원천 그룹 기준 분할, 동일 상담에서 만든 여러 학습 행의 결속, 분할 간 중복·근접 중복, 평가용 데이터의 개발 노출 이력 |
| 추적성과 재현 가능성 | 5 | 수령→적재→선별→학습 후보 수량 대조, 원천·버전·변환 코드·설정·해시, 재생성 가능성, 데이터 사용 범위·비식별 처리 근거 |

각 항목은 확인된 근거에 따라 0~5점으로 판단한다. 미확인 사항과 확인된 결함을 구분하고, 결측 근거를 기능 부재로 단정하지 않는다. 동일 상담에서 파생한 학습 행 수를 독립 상담·인물 수로 세지 않는다. 데이터량이나 모델 학습 완료 여부만으로 가산하지 않는다.

데이터와 그 평가용 표본은 Git 제외 로컬 경로에서 검증한다. 문서에는 원문 없는 집계·검사 방법·해시·한계만 남기며, 학습 원문·가공 행·평가 분할을 커밋하지 않는다.

## 버전과 결과 기록

- v1~v3 평가서와 기존 수정 기록은 당시 기준의 역사로 보존한다.
- 다음 평가서는 이 기준 버전, 데이터 버전·분모·검사 범위, 앱 검사 범위, 미확인 사항을 명시한다.
- 이전 모델 점수를 새 데이터 점수로 그대로 옮기지 않는다. 데이터 근거를 확인한 뒤 새로 채점한다.
- 평가 대상이 달라졌으므로 이전 총점과의 차이를 동일 조건의 성능 향상으로 설명하지 않는다.
- 기존 [제출 범위와 검증 계약](04_제출범위와_검증계약.md)의 모델·시간 관련 연구 계획은 향후 채점의 필수 조건이 아니다. 평가 범위가 충돌하면 이 사용자 지정 기준을 우선한다.
