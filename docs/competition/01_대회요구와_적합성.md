# 대회 요구와 프로젝트의 연결

2026-10-15에 정리한 기존 공고 검토를 기준으로 합니다. 이번 문서 정리는 공고·규정을 새로 조회한 작업이 아닙니다. [HOP 공고](https://www.bioin.or.kr/board.do?num=335472&cmd=view&bid=notice) · [사업단 공고](https://www.dju.ac.kr/biohealth/na/ntt/selectNttInfo.do?nttSn=553741&bbsId=2328&mi=5702)

## 과제와 서비스의 역할

해당 분야의 핵심 과제는 **상담 대화를 분석해 우울·중독·불안을 판별하는 모델**입니다. 말씨의 현재 서비스는 주변인에게 상황에 맞는 말과 행동을 제안하는 기능입니다. 분류 근거와 서비스 활용을 연결하되 동일한 과제의 성능으로 합치지 않습니다.

| 대회에서 설명할 것 | 프로젝트에서 연결할 자료 |
|---|---|
| 대화 판별 방법·평가 | [분류 데이터·기준 모델](../current/데이터와_연구.md) |
| 사용자에게 제공할 활용 | [현재 앱의 동작](../../app/docs/RELATIONSHIP_AGENT.md) |
| 달성 범위·미완료 검증 | [현황과 할 일](../current/현황과_할일.md) |
| 발표 근거와 표현 | [슬라이드 검토](03_발표주장과_PPT검토.md) |

현재 자료만으로 대회 과제의 충분한 검증이나 주최 측 적격 판정을 확정하지 않습니다. 주변인 지원 중심의 범위가 신청서·멘토 지침에서 승인됐는지도 확인이 필요합니다.

## 데이터 규모 대조

기존 공고에는 심리상담 데이터 **1,661건**이 제시돼 있습니다. 로컬 수령·적재·선별 단계별 수량은 [데이터와 연구](../current/데이터와_연구.md#수량과-단위)에 모았습니다. 공고와 로컬 전체 상담 집계 사이의 **199건 차이**는 원인이 설명되지 않았으므로 누락·오류로 단정하지 않습니다.

## 제출 전에 확정할 항목

결선 발표 시간·장수·파일 형식·제출 마감·평가 배점은 보관된 자료만으로 확정하지 않았습니다. 신청용 전략서의 페이지 제한을 결선 발표 제한으로 적용하지 않습니다. 일정과 요건은 실제 신청 안내·멘토 지침·최신 공지에서 확인한 뒤 반영합니다.

준비할 산출물은 확정 발표자료 한 개, 데이터·모델·평가 설명, 재현 안내와 공유 가능한 시연 사례입니다. 이는 프로젝트 준비안이며 공식 제출 규격을 대신하지 않습니다.
