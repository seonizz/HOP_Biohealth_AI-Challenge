## 함께 정리한 내용

- 최상위 README와 [공통 문서 목차](../README.md), 루트 package.json 명령을 추가했습니다.
- 32개 발표 후보 슬라이드를 발표 수치·수집 도구와 같은 `presentation` 안에 모았습니다.
- AI 도구 10개의 백엔드·데이터·발표 폴더 참조를 수정했습니다. 인수인계 패키지도 `app/ai` 구조를 생성합니다.
- 기존 사용자 디렉터리로 고정된 데이터 도구 경로는 프로젝트 상대경로로 바꿨습니다. 현재 사용 안내의 로컬 실행 예시도 새 위치로 갱신했습니다.
- Markdown의 파일 링크와 기존 심볼릭 링크 11개를 새 위치에 맞췄습니다. 과거 문서 검증 도구 3개의 프로젝트 탐색도 수정했습니다.
- 코드가 직접 사용하는 API 명세·질문은행·테스트 fixture와 모듈 문서는 모듈 내부에 유지했습니다.

## 보존과 검증

통합 직전 일반 파일 **7,273개, 29,086,885,048바이트**를 기준으로 이동 기록을 만들었습니다. 변경 전 원문은 [통합 전 원문](../../archive/07_통합전_원문/)에 보존합니다. 원천 데이터·모델 관련 파일·평가 근거와 기존 4개 Git 저장소의 이력·미커밋 변경을 유지했습니다. 원격 경로와 실제 서비스 설정·비밀값은 변경하지 않았습니다.

- 앱 정적 검사 통과. 앱 테스트 **196개 통과, 33개 건너뜀**으로 통합 전후 동일합니다. DB 통합 환경을 시작하지 않았습니다.
- AI 게이트웨이 **39개 통과**.
- 데이터 **327개 통과, 8개 건너뜀**. NumPy 2.3.5가 있는 기존 Codex Python 런타임을 사용했습니다. 기존 테스트의 ResourceWarning이 출력됐으나 실패는 없습니다.
- 경로·인수인계 패키지 회귀 3개와 기존 수집 테스트 6개, **9개 통과**. 임시 폴더와 mock으로 검증해 실제 배포·설정을 실행하지 않았습니다.
- 원문 해시·파일 링크·심볼릭 링크·수정 Python 구문 검사 결과는 [검증 JSON](프로젝트통합_검증결과.json)에 기록합니다. 기존 문서의 미해결 링크는 이번 이동으로 생긴 오류와 구분합니다.

[이동 기록과 원문 해시](프로젝트통합_이동기록.json) · [현재 파일 경로 CSV](프로젝트통합_현재경로.csv)

이전 중복 정리의 CSV·JSON에는 당시 `master/HOP_*` 경로가 남아 있습니다. 이는 과거 기록이며, 현재 위치는 이번 통합 기록을 사용합니다. 보관된 기존 배포 패키지 내부의 HOP 이름도 패키지 무결성을 위해 그대로 두었습니다.

최종 확인: 원문 파일 7,273개 추적, 심볼릭 링크 11개·문서 링크 1,080개 검사에서 새 경로 오류 0개입니다. Finder 표시 메타데이터인 `.DS_Store` 2개만 통합 직전 해시와 달랐습니다. [테스트 실행 로그](통합_검증로그/)도 함께 보존했습니다.
