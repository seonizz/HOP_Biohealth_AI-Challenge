## 없앤 중복과 충돌

- AI·데이터에 중복된 서비스 문서 26개의 전체 설명을 보관했습니다. 기존 폴더에는 도구·링크 호환용 README만 남겼습니다.
- 31B의 과거 예산과 다음 작업을 현재 지시처럼 적은 인수인계 문서 2개, 패치 폴더의 앱 설명 사본 2개를 보관했습니다. 디렉터리 메타데이터를 포함한 이동 파일은 32개입니다.
- 앱 README와 기술 문서가 반복하던 동작·RAG·검증 설명을 분리했습니다. 실제 웹 검증 미완료, 현재 소스와 미배포 개선본의 차이를 공통 현황에 명시했습니다.
- API·질문 안내에서 이전 프로토콜의 자동 질문 생략을 현행 동작으로 설명하던 부분을 바로잡았습니다.
- 대회 요약·현재 구성·우선순위의 반복 본문은 기준 문서 링크로 바꿨습니다. 슬라이드별 고유 검토 표와 연구·검증 원자료는 유지했습니다.
- 과거 배포·통합검사 수치와 최신 로컬 검사 결과를 구분했고, 이전 채팅의 목표 활성 문구를 현행 안내에서 제거했습니다.

## 도구가 다시 옛 문서를 만들지 않도록 수정

패치 적용 도구는 앱의 기준 문서를 덮어쓰지 않습니다. 인수인계 도구는 공통 문서를 생성 시점의 스냅샷으로 복사하고, 예전 상태·검사 수치를 자체 본문으로 다시 생성하지 않습니다. 모델 없는 app/ai 패키지에 포함되지 않은 데이터·발표·과거 증거 링크는 원본 프로젝트 경로 안내로 바꿉니다. 실제 프로젝트 문서의 링크는 유지합니다.

생성 지표의 출처 문자열도 공통 현황으로 변경했습니다. 기존 데이터·모델 결과·검증 산출물은 재생성하지 않았습니다.

## 확인

- 패키징·문서 보존 회귀 5개와 기존 수집 테스트 11개 통과.
- 수정 Python 스크립트 4개 구문 검사.
- 현재 문서 링크·제목 앵커, 이동한 원문의 SHA-256, 코드펜스 검사.
- 주요 기준 문서에서 160자 이상 동일한 설명 문단이 여러 파일에 반복되는지 검사.
- 독립 검토에서 실행 위치와 DB 테스트 실행 조건을 보완했습니다.

자세한 수치와 검사 범위는 [검증 결과](문서정리_검증결과.json), 이동 사유와 원문은 [이동 기록](문서정리_이동기록.json) 및 [보관함](../../archive/08_문서통합_원문/)에 있습니다. 실제 서버·모델 실행이나 배포는 수행하지 않았습니다.
