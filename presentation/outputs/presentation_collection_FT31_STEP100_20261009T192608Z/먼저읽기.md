# FT31_STEP100 수집 자료

**내부 전달용**: Excel과 raw_data에는 기존 검증용 상담 입력·답변이 포함되어 있습니다.
공개 발표에는 public_answers.md의 공개 합성 자료만 사용합니다.

모델은 malssi-gemma4-31b-step100, 학습 진행은100/5,052 step입니다.
원래 입력94건을 그대로 사용했고 상담512·분류32토큰, temperature0, 동시성1, 첫 시도1회입니다.
상담63건과 행동분류31건은 서로 다른 과제입니다. 종료·형식·토큰 지표는 품질·안전성·분류 정확도 점수가 아닙니다.
서버의 실제 토크나이저로 생성 전4096 비교 예산을 확인했습니다. 현재 역사 대화 렌더링이 문서의 과거 경로와 다른32건은 preflight에 기록했습니다.
실제 HTTP 응답은 system_fingerprint를 생략합니다. 이 값은 null로 보존하고 전후 인증된 health의 동일PID·전체 체크포인트·런타임 지문으로 각 응답을 검증했습니다.
첫 DEV001의 상태 판정은 추가 생성 없이 근거를 보강해 재계산했습니다. 기존 판정 원장과 조정 기록도 보존했습니다.

기존 검증용32건의 원천ID는 전체 학습40,415행 및 step100까지 소비한800행과 겹치지 않았고, 검증4,298행에서는32건 모두 확인됐습니다. 이는 원천ID 점검 결과이며 텍스트 중복 여부 판정은 아닙니다.

Excel의 요약 수치는 metrics.json과 대조했고 모든 원래94행에 확인된 답변·상태·실제 토큰을 보존했습니다. 연결 단절 등으로 확인되지 않은 답변·토큰은 빈칸으로 유지하며 분모에서 제외하지 않습니다.
원자료 재검증: 번들 또는 표준 Python으로 `python3 verify_measurements.py <raw_data 절대경로>`를 실행합니다.
Excel 재생성: @oai/artifact-tool이 있는 번들 Node로 `node build_datasheet.mjs --ft31 <raw_data 절대경로> --output <xlsx 절대경로>`를 실행합니다.
FILE_SHA256.json은 ZIP의 모든 전달 파일에 대한SHA-256 목록입니다. 인증키·가중치·optimizer 상태는 포함하지 않았습니다.
