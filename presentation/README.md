# 발표자료

현재 발표 기준본은 [결선 실전발표 v3](final/말씨_결선_실전발표_v3.pptx)입니다. 12장과 발표노트에 사용자 흐름, 실제 앱 화면, 학습 데이터 선별·이력, 삭제 기능, 검증 범위와 질의응답을 담았습니다. [내용·노트 원본](final/말씨_결선_실전발표_v3.json)과 [결선 실전 검증팩](../docs/competition/결선_실전_검증팩_v1.md)을 함께 사용합니다.

사용자 지정 내부 기준에 따라 모델 자체와 처리시간은 평가에서 제외하고 학습 데이터를 검증합니다. 이는 공식 결선 평가표의 변경이 아닙니다. 실제 사람 검토·도입·리허설·제출 완료를 주장하지 않습니다. 검사 수는 [고도화 v1](../docs/competition/결선_고도화_v1.md)의 최신 근거와 맞췄으며, v6 수치는 노트에서 과거 검사로 구분합니다.

이전 [근거정합본 v2](final/말씨_결선_근거정합본_v2.pptx)는 그대로 보존하며, 32개 후보는 [slides](slides/)에 남깁니다. [PPT 검토](../docs/competition/03_발표주장과_PPT검토.md)는 과거 후보의 기록입니다. 발표에는 현재 v3 한 개를 사용해 서로 다른 버전의 숫자가 섞이지 않게 합니다.

| 필요한 자료 | 위치 |
|---|---|
| 발표에 쓸 데이터·연구 수치와 해석 | [데이터와 연구](../docs/current/데이터와_연구.md) |
| 현재 구현·미완료 상태 | [현황과 할 일](../docs/current/현황과_할일.md) |
| 발표 수치 추출 방법 | [추출·활용안](발표용_데이터_추출_활용안.md) |
| 재계산 가능한 원시 기록 | [2026-10-09 비교 기록](outputs/presentation_automatic_20261009T132307Z/comparison.md) · [지표 JSON](outputs/presentation_automatic_20261009T132307Z/metrics.json) |
| 수집 절차 | [에이전트 수집 지침](에이전트용_발표수치_수집지침.md) |
| 분류 출력 형식 검토 | [검증 부록](LLM_학습전후_분류평가.md) |

저장된 결과의 날짜·모델·입력 조건을 그대로 표시합니다. 형식 유효율·종료율과 의미 품질, 분류 성능을 같은 점수로 설명하지 않습니다.

사용자 지정에 따라 모델·학습·평가 상세는 서비스 화면에 넣지 않고 문서와 발표자료에 보관합니다. [UI 정보 원칙](../app/docs/UI_CONTENT_POLICY.md).

이전 v2 덱은 v3.6.2까지의 근거를 보존합니다. v3.7·v3.8 당시 안전 인용·근거 ID·평가 계측 수정과 제한된 실측은 [수정 v3](../docs/competition/결선_재평가_지적_수정_v3.md), [수정 v4](../docs/competition/결선_재평가_지적_수정_v4.md)의 연구 이력입니다. 이를 최신 데이터 품질이나 상담 효과의 대체 근거로 사용하지 않습니다.
