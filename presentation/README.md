# 발표자료

발표 후보는 [slides](slides/), 과거 덱별 수정사항은 [PPT 검토](../docs/competition/03_발표주장과_PPT검토.md)에서 확인합니다. 파일명에 ‘최종’이 있어도 제출 확정본으로 지정한 것은 아닙니다.

| 필요한 자료 | 위치 |
|---|---|
| 발표에 쓸 데이터·연구 수치와 해석 | [데이터와 연구](../docs/current/데이터와_연구.md) |
| 현재 구현·미완료 상태 | [현황과 할 일](../docs/current/현황과_할일.md) |
| 발표 수치 추출 방법 | [추출·활용안](발표용_데이터_추출_활용안.md) |
| 재계산 가능한 원시 기록 | [2026-10-09 비교 기록](outputs/presentation_automatic_20261009T132307Z/comparison.md) · [지표 JSON](outputs/presentation_automatic_20261009T132307Z/metrics.json) |
| 수집 절차 | [에이전트 수집 지침](에이전트용_발표수치_수집지침.md) |
| 분류 출력 형식 검토 | [검증 부록](LLM_학습전후_분류평가.md) |

저장된 결과의 날짜·모델·입력 조건을 그대로 표시합니다. 형식 유효율·종료율과 의미 품질, 분류 성능을 같은 점수로 설명하지 않습니다.
