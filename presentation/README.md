# 발표자료

**자료 위치 정리(2026-11-10):** v6 기준본은 `final/`, 이전 v2~v5와 사용자가 과거로 확정한 후보 32개는 [archive](archive/README.md)에 보관했습니다.

**2026-10-27 기준** 발표는 [결선 실전발표 v6 검수본](final/말씨_결선_실전발표_v6_검수본.pptx)을 사용합니다. 기존 14장과 카드 화면을 유지하면서 최신 데이터 41,276행, 개발 노출·긴 문구 중복, 공개 대안 조사, 앱·복원 검사와 실제 관찰 미완료 상태를 반영했습니다. [내용·발표자 노트](final/말씨_결선_실전발표_v6_검수본.json), [엄격 평가 보완·재평가](../docs/competition/결선_엄격평가_보완과_재평가_2026-10-27.md), [대안 비교 근거](../docs/competition/결선_대안비교_근거보강_2026-10-27.md), [운영·도입 실행팩](../docs/competition/결선_운영과_도입_실행팩_2026-10-27.md)을 함께 사용합니다.

사용자 지정 내부 기준에 따라 모델 자체와 처리시간은 평가에서 제외하고 학습 데이터를 검증합니다. 이는 공식 결선 평가표의 변경이 아닙니다. 같은 엄격 기준의 재평가는 **50→53/90점**, 현장 발표·Q&A 10점은 유보입니다. 실제 사용자 관찰 0명, 새 검토 준비 575행의 사람 승인 0, 독립 test·기관 승인·실제 발표 리허설·제출은 미완료입니다. 앱 회귀 1,722개, 합성 비교 8상황·23조건, 합성 DB 복원 11조건은 서로 다른 분모이며 실제 사용 성공률로 합산하지 않습니다.

이전 [실전발표 v5](archive/final_v2-v5/말씨_결선_실전발표_v5.pptx)·[v4](archive/final_v2-v5/말씨_결선_실전발표_v4.pptx)·[v3](archive/final_v2-v5/말씨_결선_실전발표_v3.pptx)·[근거정합본 v2](archive/final_v2-v5/말씨_결선_근거정합본_v2.pptx)는 당시 근거로 보존합니다. [v10의 76/90](../docs/competition/결선_적대적_재평가_v10.md)과 당시 앱 391개·데이터 245개·평가 도구 24개·Git 검사기 29개도 과거 기록이며 현재 점수·검사 수로 인용하지 않습니다. 32개 과거 후보는 [후보 아카이브](archive/slide_candidates_2026-10-10/README.md)에 보관합니다. 실제 최종 제출 규격과 과제 범위 승인은 아직 확인하지 못했으며, 모집 신청서의 10쪽 조건을 결선 PPT 조건으로 옮기지 않습니다.
