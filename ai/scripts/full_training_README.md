## 내용 허용과 최종 학습 승인을 구분

44,704행은 admission v2의 내용·노출 검사 허용본입니다. 이후 구성 실험에는 추가 검토 조건이 있습니다. 예를 들어 v2 이후에는 과거 assistant 문맥의 의학 관련 표현 4,003행을 추가 보류한 40,701행을 선택 모집단으로 사용했습니다. 따라서 이 허용본을 모든 후속 조건을 통과한 최종 승인본으로 해석하지 않습니다. 자세한 정책·행별 장부는 각 `composition_v*/`와 `malssi_partial_exposure_20261015/`에 그대로 들어 있습니다.

v2–v8은 원상담에서 목적·길이·균형에 맞춰 고른 서로 겹치는 대안입니다. v9는 원상담 v8을 보존하면서 주변인 지원·앱 과업 419행을 별도로 추가했습니다. v10은 그 419행의 토큰 검증, v11은 같은 행들의 가중 정책입니다. **575행은 원상담 45,974행을 단순 필터링한 최종 개수도 아닙니다.**

보존용 아카이브에는 검토 대기·보류·과거 대안도 있습니다. 전체 폴더의 모든 JSONL을 한 train 파일로 합치지 않습니다. 기존 validation은 개발 검토에 사용됐으며 독립 test나 임상 승인으로 표시하지 않습니다.

## 무결성과 제외 항목

`FULL_MANIFEST.json`은 포함한 모든 파일의 크기·SHA-256·원래 상대경로를 기록합니다. ZIP 생성 후 모든 항목을 다시 읽어 해시를 대조했습니다. `FILTER_VERIFICATION.json`에는 45,974행의 장부 대조, 44,704/1,270 분리와 원문 행 바이트 보존 결과가 있습니다.

새 학습 승인·라벨 수정·재분할·GPU 학습은 수행하지 않았습니다. GPU 서버에는 접속하지 않았습니다. 캐시(`__pycache__`, `.pyc`, `.DS_Store`), 실행 `.log`, 다른 포함 폴더와 중복인 ZIP 심볼릭 링크만 제외했으며 상세 목록은 manifest에 있습니다. 실제 데이터와 정책·검토 JSON/JSONL은 포함합니다.

학습 데이터는 Git에 커밋하거나 공개 업로드하지 않습니다. 이 ZIP은 별도 학습 환경으로 옮길 로컬 보존본입니다.
