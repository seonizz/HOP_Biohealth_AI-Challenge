# 다음 에이전트에게 전달할 요청문

아래 문장을 ZIP과 함께 새 에이전트에게 전달할 수 있다. 현재 작업에서 다른 에이전트나 대화로 자동 전송하지 않았다.

---

첨부한 말씨 학습 인수인계 ZIP을 이어받아 줘. 먼저 `00_에이전트_인수인계.md`, `docs/검증_및_인수인계.md`, `handoff/STATUS.json`, `README.md`를 읽고 완료/미실행 상태를 확인해.

최종 목표는 불안·우울·중독을 겪는 사람의 가족과 주변인을 돕는 말씨 상담 에이전트 모델이야. 이번 단계는 맥락이 보존된 원본 상담사 응답을 학습하는 1단계 SFT이고, 문장·단어 자료는 보조 분석용이야. 보호자 관점을 원문에 임의로 덧씌우거나 AI 초안을 승인된 정답으로 넣지 마.

모델은 Gemma 4 31B IT, Unsloth 4비트 QLoRA를 사용하고 전용 GPU 서버에서 작업해. 서버 규칙을 읽고 `/home/slim/choieram` 하위의 전용 Python 환경·작업 폴더를 사용해. 물리 GPU 0의 지정 UUID를 사용하되, 다른 작업이 쓰고 있으면 중단하고 상태를 알려줘. 다른 GPU나 다른 프로세스에는 손대지 마.

패키지의 모델·환경·코드·데이터 지문을 확인한 뒤 준비 검사를 실행해. 실제 31B optimizer·PEFT 저장/재개는 아직 미실행이므로, 긴 행 canary에서 2회 업데이트·저장 후 새 프로세스로 복원해 1회 추가 업데이트되는 것을 검증하고, 통과한 경우 초기 모델에서 본 학습을 진행해. 데이터는 `data/train.jsonl.gz` 15,512건과 `data/validation.jsonl.gz` 1,724건을 사용해. `source_reference`, `analysis_only`, 합성 fixture는 생성 학습에 섞지 마.

실패한 검증을 통과로 바꾸거나 OOM을 숨기지 말고, 증거를 보존해 수정/재검증해. 31B 자원이 부족하면 12B 모델과 설정을 별도로 고정하고 검증한 뒤 전환해. 완료하면 adapter·재개 체크포인트 경로와 해시, 실제 업데이트 수, B0/B1 검증 손실, GPU 메모리, 미검증 HOP 과업 범위를 정리해줘.
