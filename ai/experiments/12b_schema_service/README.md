# 12B 스키마 제약 실험 서비스

2026-11-17 `runtime/ubuntu12b-final-r4-20261117/`에서 검증 중인 서비스의 코드만 보존한 사본입니다. 요청·응답·학습 데이터·모델·환경·인증·프로세스 상태는 포함하지 않습니다. 이 폴더를 Git에 반영해도 앱 모델 설정이 바뀌거나 서비스가 실행되지 않습니다.

`service.py`는 기존 Ubuntu 전용 모델과 읽기 전용 가상환경, `boundary.py`·`support.py`·`gpu_worker.py` 런타임, 격리 XGrammar 의존성 overlay를 필요로 합니다. 원격 의존성을 복사하거나 설치하지 않았습니다. 지정 작업 폴더와 캐시 경계 및 GPU 단독 사용 확인을 유지합니다. 실제 실행은 별도로 승인된 격리 배포 절차를 통해서만 수행해야 하며, 이 경로에서 직접 실행하는 일반 앱 서버가 아닙니다.

출력 기본 예산 8,192토큰을 전량 예약하고 입력과 합쳐 32,768토큰을 넘으면 `context_length_exceeded`를 반환합니다. 앱의 기존 검토 묶음 분할을 활성화하며 입력을 자르거나 미완성 JSON을 승인하지 않습니다. XGrammar 제약과 EOS·전체 출력 검증을 보존합니다.

로컬 CPU 계약 검사:

```sh
cd ai/experiments/12b_schema_service
python3 -B -m unittest test_service test_json_guard
```

실모델 질문 단계는 이전 실행에서 성공했으나 카드 생성부터 DB 저장까지의 최신 전체 검증은 진행 중입니다. 이 코드의 단위 검사 통과는 실모델 저장 성공을 뜻하지 않습니다. 모델 품질·운영 승인을 주장하지 않습니다.
