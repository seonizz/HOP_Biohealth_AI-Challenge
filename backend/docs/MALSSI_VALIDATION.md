# 말씨 백엔드 검증 기록

2026-10-09 개발 브랜치 검증입니다. 전체 명세 인수, 실전 의료·심리 평가 성능 승인, 운영 배포 완료를 뜻하지 않습니다. 이중 모델 점수 파이프라인은 별도 [설계 문서](DUAL_MODEL_PIPELINE_DESIGN.md)의 후속 구현 범위이며 아래 실제 추론 시험과 구분합니다.

## 환경

- Node.js 24.19.0, TypeScript, 실제 PostgreSQL. 테스트마다 무작위 스키마를 만들고 해당 스키마만 정리했습니다.
- API 테스트는 테이블 소유자/superuser/BYPASSRLS가 아닌 기존 제한 역할로 RLS를 검증했습니다. 다른 사용자의 실제 데이터는 입력·시험·삭제 대상으로 사용하지 않았습니다.
- 원격 서버: Intel i9-10900X 10코어/20스레드, RAM 약 125GiB. 공유 서버의 부하가 지연에 영향을 줄 수 있습니다.
- 실제 모델 시험: 물리 GPU 1번 RTX 4090 24GB, 기존 `Qwen3.8-27B-Q4_K_M` 파일, llama.cpp b11429, context 16384, parallel 1. 모델 명칭은 현장 파일 식별자입니다.
- 격리한 작업 트리와 loopback 18011 포트를 사용했습니다. 이 작업에서 시작한 테스트 서버만 시험 종료 후 정상 종료했습니다. 가중치 다운로드·학습·기존 서비스 재시작·운영 마이그레이션은 하지 않았습니다.

## 자동화 검증

| 검증 | 결과 | 범위 |
| --- | --- | --- |
| TypeScript `tsc --noEmit` | 통과 | 최종 백엔드 코드 |
| 전체 회귀 1차 | 167/167 통과, skip 0 | 기존 115개 + 당시 v2 52개, 약 329초 |
| 최종 v2 회귀 | 56/56 통과, skip 0 | 도메인 37, PostgreSQL 통합 17, HTTP 2, 약 112초 |
| production 의존성 감사 | 발견 취약점 0 | `npm audit --omit=dev --audit-level=high` |

최종 v2 실행에는 이후 추가한 계정 삭제 receipt, 삭제 원장 replay, 오래된 revision의 긴급 입력, 같은 소유자의 프로젝트 간 기억 격리 테스트가 포함됩니다. 두 행은 상당수가 중복되며 223개의 서로 다른 테스트를 뜻하지 않습니다. 최종 테스트 파일 전체에는 171개의 테스트가 있습니다. 최종 전체 171개 실행 결과는 PR CI에서 확인해야 합니다.

테스트는 구조화 문답, 부모 답변 수정, 명시적 선택, 멱등 재요청, 안전 보류, 두 worker의 전역 슬롯·lease·fence, 실패 시 입력 보존, 근거·개체 구분, 암호화/AAD, 소유자·프로젝트 격리, 동의·기억 만료·잊기·삭제·복원 억제 등을 검증합니다. 모델 출력을 주입한 통합 테스트는 실제 모델 정확도 검증과 다릅니다.

개발 중 발견하여 수정한 문제: 선택지 ID를 자유문으로 오인한 추출 후보 생성, 모델이 question_id 대신 메시지 UUID를 반환한 문제(스키마 enum/프롬프트 보완), 공유 디스크에서 마이그레이션의 기본 15초 timeout. 마이그레이션 트랜잭션에만 60초를 적용하고 일반 쿼리 제한은 유지했으며 DB 테스트 파일은 직렬 실행합니다.

## GPU 1번 실제 추론

합성 입력과 격리 DB를 사용한 단일 smoke run입니다. 지연은 p50/p95 또는 부하 SLO가 아닙니다.

| 시험 | 실측 |
| --- | ---: |
| 토큰 예산 계산 | 42ms |
| 근거 추출·스키마·개체 검증 | 4,072ms |
| 가이드 JSON 생성·검증 | 12,614ms |
| 모델 verifier | 1,034ms |
| 입력 수락부터 worker의 추출 결과 영속화 | 4,319ms |
| 확인된 기억부터 worker의 검증된 가이드 영속화 | 20,594ms |

모델 어댑터 시험은 2026-10-09 05:48 UTC, 실제 DB/worker 시험은 05:56 UTC에 통과했습니다. 후자는 합성 주변인 발화 `제가 불안해요`가 환자 정보로 바뀌지 않고 supporter 후보로 저장되고, 명시 확인 후 가이드 생성이 성공하는지 검사했습니다.

이 시험은 환자 감정·위험도 수치화의 CPU 벤치마크가 아닙니다. 새 B 평가 모델의 정확도·지연, 매 턴 B→A, 응답 후 점수 알림은 아직 시험하지 않았습니다.

## 남은 검증

명세의 240개 콘텐츠 회귀군/60개 안전군, 독립 한국어 콘텐츠 검토, v1 자료 이관, 게시 레지스트리, 승인 지식/지역 자원, 활동 기반 보관 정책, 임시 저장 물리 분리, 독립 암호화 백업·실제 pg_restore 복구, 연령/지역·관리자 권한·HTTPS·부하/SLO는 아직 완료되지 않았습니다. 자세한 구현 차이와 남은 작업은 [구현 범위](MALSSI_IMPLEMENTATION.md)를 확인해 주세요.

Docker 빌드/compose 검증과 GitHub Actions 결과는 PR의 실제 체크 상태를 기준으로 합니다. 이 파일의 로컬/원격 테스트 통과 기록만으로 CI 통과를 추정하지 않습니다.
