# 모델 학습과 추론 요약

**2026-11-10 저장된 로컬 기록 기준.** 상세 문서의 핵심 수치와 상태를 로컬 summary/status/results와 대조했습니다. 이번 정리에서 학습·추론을 재실행하지 않았으며 GPU 서버 재실행은 재허용 전까지 금지됩니다.

**31B는 학습 계산과 체크포인트 생성까지 끝났고, 역할별 생성 품질 평가와 최종 승인이 남았습니다. 최신 구성의 상담 한 턴은 통과했지만 최종 카드는 컨텍스트 한도 초과로 실패했습니다.**

## 31B 학습 상태

| 항목 | 확인된 내용 |
|---|---|
| 모델 | Gemma 4 31B IT의 기존 NF4 4비트 기반 + 새 LoRA |
| 식별자 | `malssi-gemma4-31b-cards-final-step4723` |
| 학습 구성 | 원상담 기초 → 카드 수정 → 카드 생성, 단계별 1 epoch |
| 예제 수 | train 37,773행 / validation 3,793행. 독립 상담 수와 다름 |
| optimizer step | 총 4,723 |
| validation loss | 원상담 4.988498→2.338531 / 카드 수정 0.091273→0.077405 / 카드 생성 2.239790→1.553758 |
| 완료 판정 | 체크포인트 생성·검증 완료, 역할별 평가 대기, `training_complete=false` |

다른 단계의 loss 절댓값을 과제 난도 비교에 사용하지 않습니다. loss 감소와 최종 생성 품질 승인은 별개입니다. 두 GPU는 **단일 모델의 분할 배치**에 사용됐으며 복제 모델 병렬 추론은 채택되지 않았습니다.

## 추론·서비스 검증을 모델별로 구분

| 대상·조건 | 결과 | 해석 |
|---|---|---|
| 최신 고정 31B, 상담 한 턴 | 2 POST · 261.230초 · 통과 | 단일 사례의 상담 경로 성공 |
| 같은 31B, 최종 카드 | 8 POST · 602.795초 후 실패 | 검토 묶음 입력과 출력 예약이 컨텍스트 한도를 초과. 완성 시간으로 사용하지 않음 |
| 이전 31B baseline, 최종 카드 | 31 POST · 1,905.390초 · 통과 | 다른 과거 구성의 결과이며 최신 실패를 대체하지 않음 |
| Mac 로컬 12B, 최종 카드 | 6 POST · 249.291초 · 통과 | 별도 모델·설정의 합성 사례 |
| 같은 12B, 마지막 답변→최종 저장 | 367.264초 · 통과 | 해당 사례에서 10분 목표 충족. HTTP·DB·재조회·삭제 검사 포함 |

31B 최신 실패는 초기 카드 검토 묶음의 **입력 + 출력 예약 8,192토큰**이 총 컨텍스트 **32,768토큰**을 넘은 것입니다. 8 POST 중 7회는 생성했고 마지막 1회는 입력 예산 검사에서 거절됐습니다. 카드 검토·발화 상세가 끝나지 않았으며 실제 DB 저장까지의 31B 서비스 검증도 완료된 것이 아닙니다.

31B 고정 실행은 검토 출력 압축을 끈 상태입니다. 12B와 31B의 설정이 일부 다르므로 성공·시간·압축 검증 결과를 합산하지 않습니다. 기록된 worker 정상 종료는 전체 카드 성공을 뜻하지 않습니다.
