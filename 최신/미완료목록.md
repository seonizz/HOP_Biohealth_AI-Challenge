# 미완료와 추가 검증 목록

확인일: 2026-11-10. 최신 문서와 관련 코드·테스트를 읽고 분류했습니다. 이 정리에서 모델 실행이나 앱 테스트를 새로 수행하지는 않았습니다. 과거 기획의 “미구현” 문구보다 후속 구현·검증 기록을 우선했습니다.

## 31B 모델 문서에서 확인된 우선 과제

새 [모델 요약](모델_학습과_추론_요약.md)과 [상세 문서](Gemma4_31B_모델_학습과_추론_검증_2026-11-10.md)를 반영했습니다. 학습 실행·체크포인트 생성은 끝났지만 최종 승인은 아직 아닙니다.

## 관계도 추가질문은 기능 미완료에서 제외

11월 1일 실제 Mac 로컬 모델로 **후속 답변→새 카드 생성·검토→HTTP 200 저장**을 완료한 기록이 있습니다. 같은 요청 중복 방지, 저장 후 조회 일치, 원본 기록 보존, Firefox 복원과 모바일 화면도 확인했습니다. 따라서 이전 색인의 “실제 모델 전체 검증 미확인” 분류를 바로잡았습니다.

남은 것은 **11월 10일 최적화가 반영된 현재 코드에서 후속 대화→새 카드 전체를 다시 실행한 근거 확보**와 다양한 입력 검증입니다. 최근 DB·UI 회귀 기록은 있지만 실모델 전체 재실행과는 구분합니다. 이것은 기능 자체가 없다는 뜻이 아닙니다.

## 필수 미완료와 구분할 추가 후보

- 작은 질문 결정 전용 경로, 최종 4회 호출 경로: 아직 채택·구현 완료되지 않은 최적화 후보.
- R6-b 인증 활동 갱신 축소: 조건부 보류 후보.
- 후속 대화의 새 카드 순차 전달: 현재는 저장 후 응답하며 최초 결과의 순차 표시 개선과 별도 범위.

## 외부 확인 대기

사람·전문가 승인, 독립 최종 test, 실제 사용자 관찰, 기관 도입, 최종 발표 제출 여부는 기존 문서에서 미확인으로 남아 있습니다. 이번 정리로 새 사실이 확인되지는 않았으며 앱 기능 개발과 구분합니다.
