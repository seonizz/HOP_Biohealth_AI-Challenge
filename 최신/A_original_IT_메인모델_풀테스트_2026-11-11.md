# 기존 모델 유지와 A_original IT 구성 준비·검증 기록

작성일: 2026-11-11. **사용자 요청에 따라 중지: 로컬에서 재사용할 전체 IT 베이스 가중치를 찾지 못해 다운로드를 종료했다. 메인 `.env` 전환과 실제 모델 전체 흐름은 실행하지 않았다.** 아래 단위·회귀 테스트 통과를 실제 학습 모델 검증 완료로 해석하지 않는다.

## 현재 적용 상태와 수정 내역

2026-11-11 사용자 최종 지시에 따라 기존 생성·검토 모델 `gemma4:12b`와 `http://127.0.0.1:11434/v1` 연결을 유지한다. `app/.env`는 수정하지 않았으며 A_original 다운로드·적용·추론을 재개하지 않는다. 아래 11436 런처와 manifest는 적용 전 준비물이며 앱 시작 스크립트나 자동 시작에 연결되지 않는다.

- 기존 main 반영: JSON 중복 키 거절, 명시적 오류 코드 우선 처리, 검토되지 않은 새 답변에서 이전 상태·승인·결과 무효화, 특정 strict schema 필드 누락 반복 시 블록 복구. 상세는 [오류 원인과 해결 기록](모델_JSON_컨텍스트_상태준비_원인과_해결방안_2026-11-11.md) 참조.
- 이번 추가 코드: llama.cpp의 명시적 컨텍스트 초과 오류 인식 및 원문·출력 예산 보존 회귀 테스트 2개.
- 적용 전 준비: IT 베이스·어댑터 해시 manifest, 해시 일치 후에만 실행하는 수동 로컬 런처. 가중치 자체는 제외.
- 문서: 실제 실행과 테스트 대역을 구분한 결과, 중지 이유, [남은 작업](미완료목록.md)을 기록했다.

## 모델의 정체와 베이스 선택

첨부 `A_original.zip`은 전체 모델이 아니라 LoRA 어댑터다. `adapter_config.json`은 `google/gemma-4-12B-it`, rank 8, alpha 16, dropout 0, PEFT 0.21.2를 지정한다. 사용자가 IT 모델로 학습했다고 확인했다. 가중치 656개(328쌍)는 F32이며 변환에서도 F32를 유지했다. 학습 당시 베이스 revision은 기록되지 않아 동일 revision 학습까지 증명할 수는 없다.

[고정 배포의 변환 로그](https://huggingface.co/ggml-org/gemma-4-12B-it-GGUF/raw/790d826c6ec7dc8aa0ab23af33e5b8313140a231/convert.log)는 PRIMARY → BF16 → Q8_0 경로를 기록한다. [원본 revision 기록](https://huggingface.co/ggml-org/gemma-4-12B-it-GGUF/raw/790d826c6ec7dc8aa0ab23af33e5b8313140a231/.src_sha)의 PRIMARY가 위 Google IT revision과 같다. 같은 배포의 Q4_0은 QAT 원본에서 변환했으므로 이번 일반 IT 어댑터의 베이스로 선택하지 않았다.

GGUF의 `general.base_model.0.repo_url`은 상위 모델 계보를 나타낼 수 있다. 해당 값에 `-it`가 없다는 이유만으로 non-IT 가중치라고 단정하지 않는다. 기존 Ollama 가중치는 정확한 원본을 확정하지 못해 이번 어댑터 베이스로 사용하지 않았다. Ollama 0.40.15의 모델 생성 경로는 LoRA를 거절하므로 별도 로컬 llama-server로 적용하는 준비 경로를 만들었다. 원격 GPU 서버는 사용하지 않는다.

변환 시 설치된 Transformers가 Gemma4Unified를 인식하지 못한다는 경고 후, 공식 변환기가 원본 `config.json`을 직접 읽는 경로로 성공했다. 656개 텐서 출력까지 확인했으며 실제 서버에서 어댑터 적용 확인은 별도 미완료다.

## 실제 모델 전체 흐름과 집계 방법

미실행. 전체 활성 문항을 유지하는 새 합성 문진으로 다음을 검증할 준비를 마쳤다. 기존처럼 문맥에 따른 질문 생략은 허용하고, 미응답을 사실로 만들어 저장하지 않는다.

1. 전체 문진과 필요한 확인 질문, 관찰·관계 기억·상태 검토를 통한 준비 완료.
2. 실제 기관 안내 분류 호출, 초기 카드 생성 및 독립 검토.
3. 암호화 저장·동일 내용 재조회·같은 결과 요청의 추가 모델 POST 0회.
4. 후속 대화·확인 질문·새 카드·완료·원본 카드 불변.
5. 다른 사용자 접근 거절과 기록·문진·후속 대화 삭제.

각 실행에서 물리 모델 POST, GET, 실패한 HTTP, 네트워크 오류, 검증 실패, 재시도와 작업 전체 재시작을 분리해 기록한다. 단계별 벽시계 시간과 각 호출의 헤더 도착·본문 종료 시간을 기록한다. 병렬 호출 시간의 합계를 전체 시간으로 표현하지 않는다. 제공되지 않은 token usage는 `null`로 남긴다. 실제 모델 출력·원본 로그는 Git 제외된 `runtime/a-original-main-20261111/full-test/runs/`에 보관한다. 이 HTTP 검증은 브라우저 화면 렌더링 검사를 포함하지 않는다.

## 보관한 실행 파일과 향후 재현 절차

- `ai/local_api/a_original_manifest.json`: 모델·어댑터 해시와 출처, 실행 설정.
- `ai/local_api/run_a_original.py`: 두 파일 해시 검증 후 루프백 전용 실행. `--check`, `--print-command` 제공.
- `runtime/a-original-main-20261111/full-test/`: 격리 DB·전체 회귀·실제 모델 검증기 및 상세 로그(로컬 전용).

현재는 실행을 중지한 상태다. 다음 명령은 향후 적용을 다시 요청받고 베이스 준비·격리 DB 생성을 마쳤을 때 사용할 참고 절차이며 이번 게시 작업에서 실행하지 않는다.

```sh
python3 ai/local_api/run_a_original.py --check
python3 ai/local_api/run_a_original.py
node --env-file=app/.env runtime/a-original-main-20261111/full-test/run.mjs --base-url http://127.0.0.1:11436/v1 --model hop-a-original-12b
```

현재 미완료: 베이스 다운로드와 해시 검증, 서버 실제 로딩·LoRA 활성 확인, 메인 환경 전환, 실제 모델 전체 테스트 및 호출/오류/시간 최종 집계. 테스트 컨테이너는 소유 식별자를 검증한 후 정리했다. 가중치·압축 파일·환경변수·원본 출력은 Git 업로드 대상에서 제외한다.

## 중지 시점 결과

사용자의 “찾아보고 없으면 멈춰” 지시에 따라 Documents, Downloads, Desktop, Hugging Face 캐시, Ollama 저장소의 파일명 258,020개를 조사했다. 완성된 Gemma 4 12B IT 베이스 파일은 찾지 못했다. 발견된 이번 첨부 파일은 어댑터이고, 학습 데이터 압축·토큰 파일은 모델 가중치가 아니다. 기존 Ollama `gemma4:12b`의 정확한 원본 revision은 확인되지 않았다. 네트워크로 연결된 SMB 볼륨은 로컬 가중치 검색 범위에서 제외했다. 검색 상세는 Git 제외 `runtime/a-original-main-20261111/local-weight-search.json`에 있다.

- 이번 IT 가중치 다운로드 프로세스를 종료했다. 부분 다운로드 파일은 로컬 runtime에 보존했다.
- 이번 테스트용 PostgreSQL 컨테이너만 정리했다. 기존 앱·Ollama 설정과 다른 작업의 프로세스는 유지했다.
- 새 학습 모델을 통한 실제 생성 호출: **0회, 미실행**. 실제 호출 오류율·생성 시간은 **측정 불가**이며 0오류나 0초 성공으로 표현하지 않는다.
- 메인 전환·전체 실모델 검증은 미완료다. 중지 당시에는 변경을 로컬에 보존했다. 후속 사용자 요청으로 코드·준비 설정·문서만 main 게시 대상으로 정리했으며, 기존 모델 유지와 실모델 검증 미완료 상태는 그대로다.
