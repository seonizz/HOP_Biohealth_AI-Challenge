# 말씨 모델 평가 기획 요약

2026-11-12 · 상세 기획서 v1.7 기준 · **기획 단계 / 평가 미실행**

## 무엇을 비교하나

같은 IT 실행 베이스에 **A_original 어댑터를 적용한 경우와 적용하지 않은 경우**를 비교한다. 질문 판단, 주어진 근거 선택, 정정 이후 근거 갱신이 달라지는지 확인한다. 큰 개선을 미리 가정하지 않는다.

## 얼마나 평가하나

**12개 사례 × 5개 과제 × 2개 모델 = 총 120개 요청**이다. 각 요청은 최초 1회만 보내며 재시도·추가 생성은 하지 않는 계획이다.

| 과제 | 두 모델 합계 | 확인할 내용 |
|---|---:|---|
| 질문 유지·생략 | 24개 | 이미 답한 질문, 필요한 질문, 맥락상 불필요한 질문 구분 |
| 현재 근거 선택 | 24개 | 제공된 후보에서 필요한 근거를 선택하고 누락·오선택 방지 |
| 정정 후 근거 갱신 | 24개 | 올바른 대상에 최신 근거를 유지하고 폐기된 근거의 현재 정보 복귀 방지 |
| 정상 초안 검토 | 24개 | 올바른 초안을 불필요하게 반려하지 않는지 |
| 오류 초안 검토 | 24개 | 오류 하나를 넣은 초안을 거절하는지 |
| 합계 | **120개** | 생성 관련 72개 + 검토 전이 48개 |

## 어떤 사례를 쓰나

다음 6개 계열에 기본 사례와 경계 사례를 하나씩 둔다. 학습 원문을 복사하지 않고 새 합성 사례로 구성한다.

1. 이미 답한 정보를 다른 표현으로 전달
2. 답하지 않은 질문이 필요한 경우와 맥락상 불필요한 경우
3. 보고자와 정보 대상이 다른 발언
4. 명시적인 부정과 알 수 없는 정보
5. 정정한 뒤 과거 발언이 다시 인용되는 경우
6. 실제로 한 행동과 앞으로 할 계획

이는 입력의 변화 유형이다. 출력이 근거 선택만 지원하는 과제에서 화자·시점·부정을 독립적으로 추론했다고 주장하지 않는다.

## 무엇으로 채점하나

**6개 지표:** 원시 JSON·스키마 유효율(M01), 질문 판단 Macro F1(M03), 현재 근거 선택 Micro F1(M06), 정정 후 현재 근거 갱신율(M07), 승인·거절 F1(M09), 정상 초안 처리 실패율(M11). M06·M07은 근거 선택·갱신에 한정한 변형 지표이며 자유 서술의 전체 의미 정확성이 아니다.

두 모델에 같은 입력·출력 계약을 제공하고 JSON 강제 생성은 사용하지 않는다. 원시 형식 점수와 사전 추출 규칙을 적용한 내용 점수를 분리한다. 모든 요청은 독립적으로 만들며 정정 전 상태만 입력한다. 최신 정답·앞 요청의 모델 출력·검토 정답을 입력에 섞지 않는다.

## 발표에서 보여 줄 근거와 한계

지표별 값·분모·실패 수와 함께 **기준 실패→후보 성공**, **기준 성공→후보 실패**, 둘 다 성공·둘 다 실패를 모두 공개한다. 개선 사례만 골라 발표하지 않는다. 사람·AI 심사는 필수가 아니며 채점기가 해석하지 못한 결과는 임의 오답으로 만들지 않고 해당 비교를 보류한다.

12개 사례는 독립 표본 120개가 아니다. 이번에는 신뢰구간·통계적 우월성을 주장하지 않는다. 첨부 어댑터와 로컬 A 학습 자료의 연결은 미확인이고, 로컬 A 자료에 검토 과제와 `not_needed` 양성 정답이 확인되지 않아 해당 결과는 전이·일반화 관점으로 구분한다. 카드 유용성·전체 서비스 품질·임상 안전성은 평가 범위 밖이다.

**현재 완료한 것은 문서 설계·검토다.** 사례·정답·관측 가능한 출력 필드·채점기·모델 식별 조건의 준비와 검증이 남아 있으며, 평가는 아직 실행하지 않는다.
